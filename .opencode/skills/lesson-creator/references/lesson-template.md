# НАЗВА УРОКУ

Вступ — 1-2 абзаци. Що учень дізнається з цього уроку і навіщо це
потрібно. Пиши простою мовою, уникай академічного стилю.

```python-runner
# Перший інтерактивний приклад — мінімальний, "щоб побачити як це працює"
print("Привіт, Python!")
```

## Розділ 1. Назва

Пояснення концепції. Мінімум води, максимум конкретики.

```python
# Менший приклад коду (НЕ runner — просто ілюстрація синтаксису)
for i in range(3):
    print(i)
```

```python-runner
# Інтерактивний приклад — учень може змінити і запустити
x = 5
y = 10
print(x + y)
```

## Де? Як? Коли?

### 🌍 Де це використовується в реальному світі?

- **Сфера 1**: конкретний приклад з поясненням
- **Сфера 2**: ще один приклад
- **Олімпіади**: де це зустрічається в задачах

### ⚙️ Як це працює в Python?

- Особливість реалізації, яку варто знати
- Quirk мови, на який часто натикаються
- Внутрішні механізми (якщо релевантно)

### 🎯 Коли обирати / застосовувати?

- **Ситуація A** → використовуй підхід X
- **Ситуація B** → використовуй підхід Y
- Чек-ліст або таблиця прийняття рішення
