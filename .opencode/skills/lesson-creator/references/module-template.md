# Шаблон: index.md модуля

Оглядова сторінка модуля, що створюється разом із уроками і задачами.

## Коли використовувати

- При створенні нового модуля
- При значному розширенні існуючого модуля

## Повний шаблон

```markdown
---
title: Модуль N — Тема модуля
---

# Модуль N. Тема модуля

[вступ — 1-2 абзаци, що учень дізнається і навіщо це потрібно.
Пиши простою мовою, без академічного стилю. Уникай кліше "у даному
модулі ми розглянемо" — пиши конкретно.]

## Уроки

1. [Урок 1 — Коротка назва](lessons/01-slug.md) — стислий підзаголовок
2. [Урок 2 — Коротка назва](lessons/02-slug.md) — стислий підзаголовок
3. [Урок 3 — Коротка назва](lessons/03-slug.md) — стислий підзаголовок
4. [Урок 4 — Коротка назва](lessons/04-slug.md) — стислий підзаголовок
5. [Урок 5 — Коротка назва](lessons/05-slug.md) — стислий підзаголовок

## Після модуля ви зможете

- [ ] Конкретна навичка, яку учень опанує
- [ ] Ще одна навичка
- [ ] І ще одна
- [ ] (зазвичай 3-5 пунктів)
```

## Конвенції

### Заголовок H1

`# Модуль N. Тема модуля`

- "Модуль" + номер + крапка + тема
- Тема — конкретна, без зайвих слів

### Список уроків

- Нумерація з 1
- Формат: `N. [Урок K — Назва](lessons/KK-slug.md) — стислий підзаголовок`
- Стислий підзаголовок допомагає зрозуміти про що урок (одне речення)
- Останній пункт — **завжди** посилання на сторінку задач модуля

### Чек-ліст "Після модуля ви зможете"

- 3-5 конкретних навичок
- Починай з дієслова у формі інфінітиву ("реалізовувати", "застосовувати", "аналізувати")
- Уникай абстрактних формулювань ("зрозуміти", "знати")
- Чек-літ (`- [ ]`) — щоб учень міг позначити виконане

### Рівень модуля

Якщо модуль має чіткий рівень складності, додай позначку:

```markdown
!!! abstract "Рівень: початковий+"

    Модуль розрахований на учнів, які вже знають основи Python
    і вміють працювати з циклами.
```

Або коротко — у першому абзаці вступу.
