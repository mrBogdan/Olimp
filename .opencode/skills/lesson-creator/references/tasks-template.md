# Шаблон: Сторінка задач модуля (`NN-tasks.md`)

Сторінка задач модуля — це **окрема сторінка** (не урок), яка
створюється автоматично при генерації модуля. Вона містить 5-10
комплексних задач на весь матеріал модуля.

## Коли використовувати

- При створенні нового модуля (обов'язково!)
- При розширенні існуючого модуля новими задачами

````markdown
# Задачі модуля N — Тема модуля

!!! info "Як працювати із задачами"

    Тут зібрані задачі на **весь матеріал модуля**. Кожна задача має
    інтерактивне поле для розв'язку та приховані тести. Натисни
    **▶▶ Run Tests**, щоб перевірити свою відповідь.

    Складність зростає: спочатку прості (Easy), потім складніші
    (Medium), в кінці — задачі рівня олімпіад (Hard).

    ```task-runner {data-task-id="task-1-slug"}
````

## Конвенції для задач модуля

!!! important "Обов'язкові вимоги"

    1. **Кількість**: 5-10 задач (типово 7)
    2. **Категорії**: 2-3 групи за темою або складністю
    3. **Складність**: easy (50%) → medium (35%) → hard (15%)
    4. **Кожна задача має**:
       - Умову з **вхід/вихід/обмеження/приклад**
       - `task-runner` для автоперевірки
       - Підказку (collapse)
       - Розв'язок (collapse)
    5. **Тести**:
       - 3-5 тестів на задачу
       - Обов'язково edge cases
       - Для олімпіадних задач — обмеження і бажана складність

## Генерація тестів: чек-ліст

Для кожної задачі продумай тести з таких категорій:

- [ ] **Приклад з умови** — щоб учень міг звірити формат
- [ ] **Мінімальний випадок** — `n=0`, `n=1`, порожній масив
- [ ] **Типовий випадок** — середні значення
- [ ] **Edge case** — максимальні/мінімальні значення, граничні умови
- [ ] **Складний випадок** — для задач підвищеної складності

## Як адаптувати під рівень модуля

### Початковий рівень (модулі 1-3)

- 5-7 задач, переважно Easy
- Прості edge cases (`n=0`, `n=1`)
- Очікувана складність `O(n)` або `O(n²)`

### Середній рівень (модулі 4-5)

- 6-8 задач, Easy + Medium
- Edge cases з порожніми/максимальними значеннями
- Очікувана складність `O(n log n)` для деяких задач

### Просунутий/олімпіадний (модулі 7-9)

- 7-10 задач, переважно Medium + Hard
- Edge cases з граничними умовами
- Задачі з обмеженнями `n ≤ 10⁵` або `10⁶`
- Очікувана складність `O(n log n)` для олімпіадних
- Можна додати задачі з минулих олімпіад
