# Python для олімпіад

Курс Python для підготовки учнів до олімпіад з програмування. Побудований як
поступовий рух від початкового рівня до олімпіадного — кожен модуль відкриває
нову тему і підвищує складність.

## Стек

- [MkDocs](https://www.mkdocs.org/) + [Material](https://squidfunk.github.io/mkdocs-material/)
- [Pyodide](https://pyodide.org/) — Python у браузері (бекенд не потрібен)
- GitHub Pages + GitHub Actions

## Локальний запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
mkdocs serve
```

Сайт буде доступний на `http://localhost:8000`.

## Структура курсу

| # | Модуль | Рівень |
|---|--------|--------|
| 1 | Основи Python | початковий |
| 2 | Колекції (рядки, списки, словники) | початковий |
| 3 | Функції | початковий+ |
| 4 | Вступ до алгоритмів (складність, пошук) | середній |
| 5 | Рекурсія | середній+ |
| 6 | Сортування | середній+ |
| 7 | Структури даних (стек, черга, дерева, купа) | просунутий |
| 8 | Рядки та підрядки (KMP, Z-функція) | олімпіадний |
| 9 | Олімпіадні техніки | олімпіадний |

## Як додати новий урок

Структура уроку, шаблон та чек-ліст описані в скілі
`.opencode/skills/lesson-creator/SKILL.md`. Кожен урок повинен містити блок
**«Де? Як? Коли?»** з реальними прикладами використання.

## Деплой

При пуші в `main` GitHub Actions збирає сайт і публікує на GitHub Pages
(див. `.github/workflows/deploy.yml`).
