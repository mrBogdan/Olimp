# Python для олімпіад

Курс програмування на Python для підготовки учнів до олімпіад. Побудований як
поступовий рух від першого `print("Привіт")` до складних олімпіадних задач.

## Як влаштований курс

!!! tip "Принцип побудови"

    Кожен модуль відкриває одну велику тему і підвищує складність. Починаємо
    з основ мови, проходимо колекції та функції, занурюємось в алгоритми й
    структури даних, і завершуємо класичними олімпіадними техніками.
    Кожен урок містить інтерактивні приклади, які можна запустити прямо в
    браузері, та задачі для самостійного розв'язання.

## Як працювати з курсом

1. **Читайте урок** — теорія подана коротко з акцентом на практику.
2. **Запускайте приклади** — кожен код має кнопку ▶ Run. Натискайте й
   експериментуйте: змінюйте значення, ламайте, виправляйте.
3. **Розв'язуйте задачі** — після кожної великої теми є задачі. Спробуйте
   розв'язати самостійно, перш ніж дивитись розв'язок.
4. **Рухайтесь послідовно** — кожен модуль спирається на попередній.

## Інструменти

!!! info "Інтерактивний Python"

    Прямо в браузері запускається справжній Python (через [Pyodide](https://pyodide.org/)).
    Не потрібно нічого встановлювати — натисніть **▶ Run** у будь-якому блоці
    з кодом. Ctrl/⌘+Enter теж запускає код.

!!! info "Підсвітка синтаксису і копіювання"

    Усі блоки коду мають підсвітку синтаксису і кнопку копіювання (вгорі праворуч).

Готові? Починайте з [Модуля 1 → Основи Python](modules/m01-basics/index.md).
