# Модуль 1. Основи Python

Перший модуль закладає фундамент: ми вчимося думати як програміст і
опановуємо базові інструменти мови — змінні, типи даних, оператори,
введення/виведення, умовні конструкції та цикли.

## Уроки

1. [Змінні та типи даних](lessons/01-zminni.md) — числа, рядки, булеві значення
2. [Оператори та вирази](lessons/02-operators.md) — арифметика, порівняння, логіка
3. [Введення і виведення](lessons/03-io.md) — `input()`, `print()`, форматування
4. [Умовні конструкції](lessons/04-conditions.md) — `if`, `elif`, `else`
5. [Цикли](lessons/05-loops.md) — `while`, `for`, `break`, `continue`
6. [Задачі модуля 1](lessons/06-tasks.md) — практика на весь матеріал
