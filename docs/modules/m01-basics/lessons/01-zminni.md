# Змінні та типи даних

Змінна — це **іменована комірка пам'яті**, яка зберігає значення. У Python не
треба заздалегідь вказувати тип змінної — мова визначає його автоматично за
присвоєним значенням. Це називається **динамічною типізацією**.

```python-runner
name = "Олімпія"   # рядок (str)
age = 15           # ціле число (int)
height = 1.68      # дробове число (float)
is_student = True  # булеве значення (bool)

print(type(name), type(age), type(height), type(is_student))
```

## Базові типи

| Тип | Опис | Приклад |
|---|---|---|
| `int` | Цілі числа | `-7`, `0`, `42`, `10**100` |
| `float` | Дробові числа | `3.14`, `-0.5`, `2e10` |
| `str` | Рядки (текст) | `"Привіт"`, `'Python'` |
| `bool` | Логічні значення | `True`, `False` |
| `NoneType` | Відсутність значення | `None` |

## Імена змінних

!!! warning "Правила іменування"

    - Починаються з літери або `_`, не з цифри
    - Містять літери, цифри, `_`
    - **Регістр має значення**: `age` і `Age` — різні змінні
    - Не можна використовувати зарезервовані слова: `if`, `for`, `class`…

```python-runner
# ✅ Правильно
student_name = "Богдан"
_private = 42
camelCase = "ok"

# ❌ Неправильно (спробуйте розкоментувати)
# 2students = "two"      # починається з цифри
# my-name = "Богдан"     # дефіс — це мінус
# class = 11             # зарезервоване слово
```

## Де? Як? Коли?

### 🌍 Де це використовується в реальному світі?

- **Веб-сайти й застосунки**: ім'я користувача (`str`), вік (`int`), баланс
  рахунку (`float`), чи активований акаунт (`bool`).
- **Ігри**: координати персонажа (`float`), рахунок (`int`), чи гравець
  живий (`bool`).
- **Наука й аналітика**: температура (`float`), кількість вимірів (`int`),
  категорія експерименту (`str`).
- **Олімпіади**: більшість вхідних даних — це числа (`int`/`float`), а
  відповідь часто треба вивести як `str` через `print()`.

### ⚙️ Як це працює в Python?

- При присвоєнні `x = 5` Python створює **об'єкт** типу `int` зі значенням
  `5` і прив'язує до нього ім'я `x`. Ім'я — це лише **посилання** на
  об'єкт.
- Змінну можна перепризначити на значення іншого типу — це і є
  динамічна типізація:

  ```python-runner
  x = 5          # int
  x = "тепер я рядок"  # str — Python не скаржиться
  print(x, type(x))
  ```

- `type(x)` повертає тип об'єкта, на який посилається `x`.
- Великі числа — без помилок: `10**100` Python опрацює як звичайне `int`.

### 🎯 Коли обирати який тип?

- **Рахунок, лічильник, індекс, N** → `int`
- **Вимірювання, відсотки, координати** → `float`
- **Текст, імена, повідомлення** → `str`
- **Прапорці, стани, умови** → `bool`
- **"Нічого" або "не визначено"** → `None`

## Типові помилки

!!! danger "Оператор присвоєння vs оператор порівняння"

    Плутанина `=` (присвоїти) і `==` (порівняти) — найчастіша помилка новачків.

```python-runner
x = 5      # присвоїти
x == 5     # порівняти (поверне True/False, але не змінить x)
print(x)   # все ще 5
```

!!! danger "Змішування типів"

    Python не зробить автоматично `int + str`. Треба явно перетворити тип.

```python-runner
age = 15
# print("Мені " + age + " років")  # ❌ TypeError!
print("Мені " + str(age) + " років")   # ✅
print(f"Мені {age} років")             # ✅ f-рядок
```

### Задача 1. Обмін значеннями (Easy)

Зчитай з клавіатури два числа в одному рядку через пробіл. Поміняй їх
місцями та виведи через пробіл.

**Вхід:** один рядок з двома цілими числами, розділеними пробілом.
**Вихід:** ті ж два числа у зворотному порядку через пробіл.
**Приклад:** `input: "3 7" → output: "7 3"`

Спробуй сам:

```task-runner {data-task-id="swap"}
# Зчитай два числа та виведи їх у зворотному порядку
```

??? hint "Підказка"

    Python підтримує множинне присвоєння: `a, b = b, a`. Щоб прочитати два
    числа з одного рядка, використай `a, b = input().split()`.

??? success "Розв'язок"

    ```python-runner
    a, b = input().split()
    a, b = b, a
    print(a, b)
    ```

### Задача 2. Площа прямокутника (Easy)

Зчитай довжину і ширину прямокутника (кожне в окремому рядку) та
виведи його площу.

**Вхід:** два рядки з цілими числами.
**Вихід:** одне число — площа.
**Приклад:** `input: "3\n4" → output: "12"`

Спробуй сам:

```task-runner {data-task-id="rect"}
# Зчитай довжину та ширину, виведи площу
```

??? hint "Підказка"

    Площа — це добуток довжини на ширину. Для зчитування скористайся
    `int(input())`.

??? success "Розв'язок"

    ```python-runner
    length = int(input())
    width = int(input())
    print(length * width)
    ```

### Задача 3. Гіпотенуза (Medium)

Зчитай довжини двох катетів `a` і `b` (дробові числа) та виведи
довжину гіпотенузи $c = \sqrt{a^2 + b^2}$.

**Вхід:** два рядки з дробовими числами.
**Вихід:** одне число — гіпотенуза.
**Приклад:** `input: "3\n4" → output: "5.0"`

Спробуй сам:

```task-runner {data-task-id="hypot"}
# Обчисли гіпотенузу за формулою c = sqrt(a^2 + b^2)
```

??? hint "Підказка"

    Скористайся `math.sqrt` або піднеси до степеня `** 0.5`. Не забудь
    `import math` на початку.

??? success "Розв'язок"

    ```python-runner
    import math
    a = float(input())
    b = float(input())
    print(math.sqrt(a*a + b*b))
    ```
