# Оператори та вирази

Оператори — це символи й команди, за допомогою яких ми виконуємо дії над даними:
додаємо числа, перевіряємо рівність, комбінуємо логічні твердження. Вираз — це
будь-яка комбінація значень, змінних та операторів, яку Python може обчислити й
перетворити на результат.

```python-runner
a = 17
b = 5

# Арифметичні операції
print("Сума:", a + b)
print("Цілочисельне ділення:", a // b)
print("Остача від ділення:", a % b)
```

## Арифметичні оператори

Python підтримує всі звичні математичні операції, а також кілька особливих:

| Оператор | Назва | Приклад | Результат |
|---|---|---|---|
| `+` | Додавання | `7 + 3` | `10` |
| `-` | Віднімання | `7 - 3` | `4` |
| `*` | Множення | `7 * 3` | `21` |
| `/` | Звичайне ділення | `7 / 2` | `3.5` (завжди `float`!) |
| `//` | Цілочисельне ділення | `7 // 2` | `3` (відкидає дробову частину) |
| `%` | Остача від ділення | `7 % 3` | `1` |
| `**` | Піднесення до степеня | `2 ** 10` | `1024` |

```python-runner
# Зверніть увагу: звичайне ділення / завжди повертає float
print(10 / 2)    # 5.0, а не 5
print(10 // 2)   # 5 (тип int)
print(2 ** 8)    # 256
```

### Секрети `//` та `%` для олімпіадника

Ці два оператори — головна зброя при роботі з окремими цифрами числа:

- `n % 10` — виділяє **останню цифру** числа (`1234 % 10` $\rightarrow$ `4`).
- `n // 10` — **відкидає останню цифру** числа (`1234 // 10` $\rightarrow$ `123`).
- `(n // 10) % 10` — виділяє **передостанню цифру** (десятки).

!!! warning "Остача з від'ємними числами"

    У Python ділення з остачею математично узгоджене: результат `a % b` завжди має той самий знак, що й дільник `b`.

    ```python-runner
    print(-7 // 3)   # -3 (округлення вниз до меншого цілого!)
    print(-7 % 3)    # 2  (бо -3 * 3 + 2 = -7)
    ```

    Це відрізняється від мов C++ чи Java, де `-7 % 3` дало б `-1`.

## Скорочені оператори присвоєння

Якщо треба змінити значення змінної та зберегти його назад, використовують скорочені оператори:

```python-runner
score = 10
score += 5   # еквівалентно: score = score + 5
score *= 2   # еквівалентно: score = score * 2
score -= 4   # еквівалентно: score = score - 4
print("Підсумковий бал:", score)
```

Працюють також: `//=`, `%=`, `**=`.

## Оператори порівняння

Оператори порівняння зіставляють два значення й повертають булевий результат — `True` або `False`:

| Оператор | Значення | Приклад | Результат |
|---|---|---|---|
| `==` | Дорівнює | `5 == 5` | `True` |
| `!=` | Не дорівнює | `5 != 3` | `True` |
| `<` | Менше | `3 < 5` | `True` |
| `>` | Більше | `3 > 5` | `False` |
| `<=` | Менше або дорівнює | `5 <= 5` | `True` |
| `>=` | Більше або дорівнює | `4 >= 5` | `False` |

### Ланцюгові порівняння

Суперсила Python — можливість писати математичні подвійні нерівності прямо в коді:

```python-runner
x = 15
# Замість (x >= 10 and x <= 20) можна писати:
print(10 <= x <= 20)  # True

# Працює навіть для трьох і більше порівнянь:
a, b, c = 1, 2, 3
print(a < b < c)      # True
```

## Логічні оператори

Для об'єднання кількох умов слугують логічні оператори:

- `and` (**І**, логічне множення) — істинне лише тоді, коли обидві умови істинні.
- `or` (**АБО**, логічне додавання) — істинне, якщо хоча б одна умова істинна.
- `not` (**НЕ**, заперечення) — змінює значення на протилежне (`not True` $\rightarrow$ `False`).

```python-runner
age = 16
has_ticket = True

# Чи пустять на фільм?
can_enter = (age >= 16) and has_ticket
print("Доступ дозволено:", can_enter)

# Пільговий проїзд: діти до 7 років АБО пенсіонери від 65
passenger_age = 70
is_free = (passenger_age < 7) or (passenger_age >= 65)
print("Безкоштовний проїзд:", is_free)
```

!!! tip "Ліниві обчислення (Short-circuit)"

    Python обчислює `and` та `or` зліва направо і зупиняється, щойно результат стає очевидним:

    - Якщо в `A and B` вираз `A` хибний, `B` навіть не перевірятиметься (бо результат гарантовано `False`).
    - Якщо в `A or B` вираз `A` істинний, `B` не обчислюється (результат уже `True`).

## Пріоритет операцій

Коли у виразі багато операторів, вони виконуються в чітко визначеному порядку:

1. Дужки `()` — найвищий пріоритет
2. Піднесення до степеня `**`
3. Унарні знаки `+x`, `-x`
4. Множення та ділення `*`, `/`, `//`, `%`
5. Додавання та віднімання `+`, `-`
6. Порівняння `==`, `!=`, `<`, `<=`, `>`, `>=`
7. Логічний `not`
8. Логічний `and`
9. Логічний `or`

```python-runner
# Без дужок: спочатку 2 * 3 = 6, потім 10 - 6 = 4
print(10 - 2 * 3)

# З дужками: спочатку (10 - 2) = 8, потім 8 * 3 = 24
print((10 - 2) * 3)
```

## Де? Як? Коли?

### 🌍 Де це використовується в реальному світі?

- **Фінанси й банкінг**: розрахунок відсотків за кредитом, розбиття копійок на гривні й копійки (`kopecks // 100` та `kopecks % 100`).
- **Ігри та графіка**: перевірка зіткнень персонажа з кордонами карти через ланцюгові нерівності `0 <= x <= screen_width`.
- **Робота з часом**: перетворення секунд у хвилини, години й дні за допомогою операторів `//` і `%`.
- **Олімпіади**: майже в кожній задачі зустрічаються розбиття чисел на цифри, кругові індекси `(i + 1) % n`, перевірка парності `n % 2 == 0` та перевірка обмежень.

### ⚙️ Як це працює в Python?

- **Нескінченна точність цілих чисел**: у багатьох мовах (C++, Java) цілі числа обмежені 32 або 64 бітами і можуть переповнюватися (`overflow`). У Python тип `int` автоматично розширюється в пам'яті: ви можете обчислити `2 ** 1000` без жодних проблем!
- **Особливості `float`**: дробові числа зберігаються у форматі IEEE 754. Через це двійковий дріб не завжди точно представляє десятковий: `0.1 + 0.2` дає `0.30000000000000004`. Пам'ятайте про це при порівнянні `float` на рівність!
- **Пріоритет `**`**: оператор степеня групується справа наліво: `2 ** 3 ** 2` означає $2^{(3^2)} = 2^9 = 512$, а не $(2^3)^2 = 64$.

### 🎯 Коли обирати / застосовувати?

- Потрібен точний цілий результат або номер кроку $\rightarrow$ використовуй `//`.
- Потрібно дізнатися, що залишилося від поділу порівну $\rightarrow$ використовуй `%`.
- Потрібно перевірити, чи число в межах $[A, B]$ $\rightarrow$ пиши ланцюгове `A <= x <= B`.
- Не впевнений у пріоритеті складного виразу $\rightarrow$ **завжди став круглі дужки `()`**. Це робить код зрозумілішим і рятує від прихованих багів.

## Типові помилки

!!! danger "Використання `/` замість `//`"

    Ділення `/` завжди створює число з плаваючою комою. Якщо задача вимагає ціле число, використання `/` призведе до помилки тестуючої системи через `.0` на кінці.

```python-runner
# ❌ Неправильно (виведе 5.0)
print(10 / 2)

# ✅ Правильно (виведе ціле 5)
print(10 // 2)
```

!!! danger "Плутанина між `=` і `==`"

    Символ `=` призначений для присвоєння значення, а `==` — для перевірки на рівність. Спроба написати `if a = 5:` викличе синтаксичну помилку `SyntaxError`.

```python-runner
a = 10
# print(a = 5)  # ❌ SyntaxError!
print(a == 5)   # ✅ Поверне False
```

!!! danger "Неправильний пріоритет логічних операторів"

    Оператор `not` має вищий пріоритет за `and`, а `and` має вищий за `or`. Якщо не ставити дужки, логіка виразу може спотворитися.

```python-runner
# Хочемо перевірити: x не належить проміжку від 1 до 5
x = 10
# ❌ Помилка: not діє тільки на (x >= 1)
print(not x >= 1 and x <= 5)   # False, хоча 10 не в проміжку!

# ✅ Правильно: використовуємо дужки
print(not (1 <= x <= 5))       # True
```

### Задача 1. Остання цифра (Easy)

Дано натуральне число $n$. Знайди та виведи його останню цифру.

**Вхід:** один рядок з цілим додатним числом $n$ ($1 \le n \le 10^9$).
**Вихід:** одна цифра — остання цифра числа $n$.
**Приклад:** `input: "123" → output: "3"`

Спробуй сам:

```task-runner {data-task-id="last-digit"}
# Зчитай число n і виведи його останню цифру
```

??? hint "Підказка"

??? success "Розв'язок"

    ```python-runner
    n = int(input())
    print(n % 10)
    ```

### Задача 2. Електронний годинник (Easy)

З початку доби минуло $N$ секунд. Виведи, скільки це повних годин та скільки повних хвилин пройшло з початку поточної години. Два числа виведи через пробіл.

Гарантується, що $N$ відповідає часу поточної доби (тобто $0 \le N < 86400$).

**Вхід:** одне ціле число $N$.
**Вихід:** два цілих числа через пробіл — години (0–23) та хвилини (0–59).
**Приклад:** `input: "3661" → output: "1 1"`

Спробуй сам:

```task-runner {data-task-id="time-convert"}
# Зчитай секунди N і виведи кількість годин та хвилин через пробіл
```

??? hint "Підказка"

    В одній годині $3600$ секунд. Кількість повних годин: `hours = N // 3600`.
    Секунди, що залишилися після годин: `remainder = N % 3600`.
    Кількість хвилин у залишку: `minutes = remainder // 60`.

??? success "Розв'язок"

    ```python-runner
    n = int(input())
    hours = n // 3600
    minutes = (n % 3600) // 60
    print(hours, minutes)
    ```

### Задача 3. Число десятків (Medium)

Дано додатне ціле число $n$, яке гарантовано має щонайменше дві цифри ($10 \le n \le 10^9$). Знайди цифру десятків у ньому (тобто передостанню цифру числа).

**Вхід:** одне ціле число $n$.
**Вихід:** одна цифра — передостання цифра числа $n$.
**Приклад:** `input: "173" → output: "7"`

Спробуй сам:

```task-runner {data-task-id="tens-digit"}
# Знайди та виведи цифру десятків числа
```

??? hint "Підказка"

    Спочатку відкинь останню цифру за допомогою цілочисельного ділення на 10 (`n // 10`), а потім візьми останню цифру результату за допомогою `% 10`.

??? success "Розв'язок"

    ```python-runner
    n = int(input())
    print((n // 10) % 10)
    ```

### Задача 4. Чи існує трикутник? (Medium)

Дано три додатні числа $a, b, c$, які задають довжини відрізків (всі три числа подано в одному рядку через пробіл). Виведи `True`, якщо з цих відрізків можна утворити невийроджений трикутник, і `False` у протилежному випадку.

Нагадаємо: трикутник існує тоді й тільки тоді, коли сума будь-яких двох його сторін строго більша за третю сторону:
$a + b > c \quad \text{і} \quad a + c > b \quad \text{і} \quad b + c > a$.

**Вхід:** три цілих числа $a, b, c$ через пробіл ($1 \le a, b, c \le 10^4$).
**Вихід:** `True` або `False`.
**Приклад:** `input: "3 4 5" → output: "True"`

Спробуй сам:

```task-runner {data-task-id="is-triangle"}
# Зчитай три числа та перевір нерівність трикутника
```

??? hint "Підказка"

    Зчитай числа за допомогою `a, b, c = map(int, input().split())`.
    Перевір умову за допомогою оператора `and` і виведи булевий результат.

??? success "Розв'язок"

    ```python-runner
    a, b, c = map(int, input().split())
    can_form = (a + b > c) and (a + c > b) and (b + c > a)
    print(can_form)
    ```
