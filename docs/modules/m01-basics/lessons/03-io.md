# Введення і виведення

Будь-яка олімпіадна чи прикладна програма працює за схемою: **отримати дані $\rightarrow$
обробити їх $\rightarrow$ вивести результат**. У Python за прийом даних відповідає
функція `input()`, а за друк результату — `print()`. У цьому уроці ми вивчимо всі
тонкощі їхньої роботи.

```python-runner
# Перевизначимо input для демонстрації
input = lambda: "Олімпія"
name = input()
print(f"Привіт, {name}! Ласкаво просимо до олімпіадного програмування.")
```

## Функція `print()`: друк без обмежень

Функція `print()` може приймати будь-яку кількість аргументів, розділених комами:

```python-runner
day = 15
month = "жовтня"
year = 2026
print("Сьогодні:", day, month, year)
```

За замовчуванням `print()` розділяє значення звичайним пробілом, а в кінці
переводить рядок на новий. Цю поведінку регулюють параметри `sep` та `end`.

### Параметр `sep` (separator)

`sep` визначає, який символ вставляти між аргументами:

```python-runner
# За замовчуванням sep=" "
print(1, 2, 3)

# sep="" — зліпити все разом
print(1, 2, 3, sep="")

# sep=":" — для форматування часу
print(12, 45, 30, sep=":")

# sep="\n" — кожен аргумент з нового рядка
print("Один", "Два", "Три", sep="\n")
```

### Параметр `end`

`end` визначає, що виводити в самому кінці виклику `print()` (за замовчуванням `end="\n"`):

```python-runner
# Виводимо числа в один рядок через пробіл:
print("Рахуємо:", end=" ")
print(1, end=" ")
print(2, end=" ")
print(3)  # тут спрацює стандартний перехід рядка
print("Готово!")
```

## Функція `input()` та перетворення типів

Функція `input()` зчитує **один рядок** із консолі аж до натискання Enter.

!!! danger "Головне правило input()"

    Функція `input()` **ЗАВЖДИ повертає рядок (`str`)**, навіть якщо користувач ввів лише цифри!

Якщо вам потрібні числа для арифметики, рядок треба явно обгорнути у функцію перетворення типу:

```python-runner
# Емулюємо введення користувачем "42"
input = lambda: "42"

raw_input = input()
print(type(raw_input))  # <class 'str'>

num = int(raw_input)    # перетворюємо на ціле число
print(type(num))        # <class 'int'>
print(num * 2)          # 84
```

- `int(input())` — зчитати одне ціле число.
- `float(input())` — зчитати число з плаваючою комою (наприклад, `"3.14"` $\rightarrow$ `3.14`).

## Зчитування кількох значень з одного рядка

В олімпіадних задачах вхідні дані майже завжди подаються в одному рядку через пробіл (наприклад: `10 20 30`).

### Метод `.split()`

Метод рядка `.split()` розбиває рядок на список слів за пробілами:

```python-runner
line = "10 20 30"
parts = line.split()
print(parts)  # ['10', '20', '30'] — це список рядків!
```

### Зв'язка `map(int, input().split())`

Це найпопулярніша конструкція в олімпіадному коді. Функція `map(int, ...)` застосовує `int` до кожного шматочка:

```python-runner
# Емулюємо введення "15 25"
input = lambda: "15 25"

a, b = map(int, input().split())
print("Сума:", a + b)
```

А якщо чисел багато і їх кількість наперед невідома? Створюємо список:

```python-runner
input = lambda: "5 10 15 20 25"
numbers = list(map(int, input().split()))
print("Список чисел:", numbers)
print("Сума всіх чисел:", sum(numbers))
```

## Сучасне форматування: f-рядки (f-strings)

Починаючи з Python 3.6, найкращим способом складати рядки є **f-рядки** (форматовані рядкові літерали). Перед лапками ставиться літера `f`, а всередині у фігурних дужках `{}` можна записувати будь-які змінні або вирази:

```python-runner
item = "зошит"
price = 24.5
count = 3

print(f"Куплено {count} шт. товару '{item}' на суму {price * count} грн.")
```

### Форматування чисел у f-рядках

Після двокрапки всередині `{}` можна задавати специфікатори формату:

```python-runner
import math

pi = math.pi
print(f"За замовчуванням: {pi}")
print(f"Два знаки після коми: {pi:.2f}")
print(f"Чотири знаки: {pi:.4f}")

# Провідні нулі для дат чи номерів (довжина 2 та 4 знаки):
day = 5
month = 9
order_id = 42
print(f"Дата: {day:02d}.{month:02d}")
print(f"Замовлення: #{order_id:06d}")
```

## Де? Як? Коли?

### 🌍 Де це використовується в реальному світі?

- **Консольні утиліти (CLI)**: взаємодія з адміністратором, інсталяційні скрипти, читання параметрів з терміналу.
- **Генерація звітів та чеків**: вирівнювання стовпчиків, округлення сум до копійок `{price:.2f}`, форматування дат і часу.
- **Олімпіади з програмування**: 100% задач автоматично тестуються через стандартні потоки введення (`stdin`) та виведення (`stdout`). Будь-який зайвий символ у виводі веде до вердикту `Wrong Answer`!

### ⚙️ Як це працює в Python?

- `split()` без аргументів розбиває рядок за **будь-якою кількістю пробільних символів** підряд (включно зі знаками табуляції `\t` і перенесення рядка `\n`), і автоматично відкидає зайві пробіли на початку й у кінці рядка.
- `print()` під капотом записує текст у `sys.stdout`. За замовчуванням буфер виводу скидається при зустрічі символу `\n`. Якщо ви використовуєте `end=""` в інтерактивних програмах, може знадобитися `flush=True`.
- Для величезних обсягів даних ($10^6$ чисел) стандартний `input()` може працювати повільно. В олімпіадах для таких задач підключають `sys.stdin.read().split()`.

### 🎯 Коли обирати / застосовувати?

- Одне число в рядку $\rightarrow$ `x = int(input())`.
- Два-три числа в одному рядку $\rightarrow$ `a, b = map(int, input().split())`.
- Невідома кількість чисел у рядку $\rightarrow$ `arr = list(map(int, input().split()))`.
- Потрібно вивести числа в рядок через дефіс чи кому $\rightarrow$ `print(*arr, sep=", ")`.
- Потрібно підставити змінні в текст або округлити дріб $\rightarrow$ **завжди обирай f-рядок `f"{x:.2f}"`**.

## Типові помилки

!!! danger "Підказка всередині input() на олімпіадах"

    Підказка на кшталт `input("Введіть число: ")` потрібна в користувацьких програмах, але **суворо заборонена в автоматичних тестуючих системах**! Текст підказки потрапляє у вивід програми, і тестер вважатиме відповідь неправильною.

```python
# ❌ Неправильно для олімпіад
n = int(input("Введіть число n: "))

# ✅ Правильно
n = int(input())
```

!!! danger "Конкатенація рядка з числом замість додавання"

    Якщо забути зробити `int()`, оператор `+` склеїть рядки (конкатенація) замість математичного додавання.

```python-runner
# ❌ Забули int:
a = "10"
b = "20"
print(a + b)        # "1020"

# ✅ Зробили int:
print(int(a) + int(b))  # 30
```

!!! danger "Спроба виконати `int(input().split())`"

    Функція `int()` вміє перетворювати лише один рядок, а `split()` повертає список рядків. Виникне помилка `TypeError`.

```python
# ❌ Помилка:
# a, b = int(input().split())

# ✅ Правильно:
# a, b = map(int, input().split())
```

### Задача 1. Привітання (Easy)

Зчитай з клавіатури одне слово або ім'я (один рядок). Виведи привітання у форматі: `Привіт, <ім'я>!`

**Вхід:** один рядок, що містить ім'я.
**Вихід:** рядок привітання за вказаним шаблоном (зверни увагу на кому та знак оклику).
**Приклад:** `input: "Оля" → output: "Привіт, Оля!"`

Спробуй сам:

```task-runner {data-task-id="greeting"}
# Зчитай ім'я та виведи вітання
```

    ```python-runner
    print(f"Привіт, {name}!")
    ```

### Задача 2. Сума трьох чисел в одному рядку (Easy)

В одному рядку через пробіл подано три цілих числа: $a, b, c$. Знайди та виведи їхню суму.

**Вхід:** три цілих числа в одному рядку через пробіл ($-10^9 \le a, b, c \le 10^9$).
**Вихід:** одне ціле число — їхня сума.
**Приклад:** `input: "1 2 3" → output: "6"`

Спробуй сам:

```task-runner {data-task-id="sum-three-line"}
# Зчитай три числа з одного рядка та виведи їх суму
```

??? hint "Підказка"

    Скористайся конструкцією `a, b, c = map(int, input().split())`, а потім виведи `a + b + c`.


### Задача 3. Красиве форматування часу (Medium)

Дано три цілих числа, кожне в окремому рядку: години $H$ ($0 \le H \le 23$), хвилини $M$ ($0 \le M \le 59$) та секунди $S$ ($0 \le S \le 59$).

Виведи час у форматі `HH:MM:SS`. Кожне число має займати рівно два символи: якщо воно менше 10, перед ним має стояти цифра `0` (наприклад, `09:05:07`).

**Вхід:** три рядки, у кожному по одному цілому числу ($H$, $M$, $S$).
**Вихід:** рядок часу у форматі `HH:MM:SS`.
**Приклад:** `input: "9\n5\n7" → output: "09:05:07"`

Спробуй сам:

```task-runner {data-task-id="format-time"}
# Зчитай три числа з трьох рядків і виведи час у форматі HH:MM:SS
```

??? hint "Підказка"

    Зчитай кожне число окремим викликом `int(input())`.
    Для виведення з провідним нулем скористайся f-рядком із специфікатором `:02d`: `f"{h:02d}:{m:02d}:{s:02d}"`.

??? success "Розв'язок"

    ```python-runner
    h = int(input())
    m = int(input())
    s = int(input())
    print(f"{h:02d}:{m:02d}:{s:02d}")
    ```

### Задача 4. Кратні числа через кому (Medium)

Дано натуральне число $n$. Виведи перші п'ять чисел, кратних $n$ (тобто $n \cdot 1, n \cdot 2, n \cdot 3, n \cdot 4, n \cdot 5$), в одному рядку через кому та пробіл: `, `.

**Вхід:** одне ціле додатне число $n$ ($1 \le n \le 10^4$).
**Вихід:** п'ять чисел через кому та пробіл.
**Приклад:** `input: "3" → output: "3, 6, 9, 12, 15"`

Спробуй сам:

```task-runner {data-task-id="mult-table-line"}

```

??? hint "Підказка"

??? success "Розв'язок"

