# Умовні конструкції

Досі всі наші програми виконувалися лінійно — команда за командою від першого рядка
до останнього. Але реальні алгоритми повинні вміти **приймати рішення**: якщо умова
виконується — робимо одну дію, якщо ні — іншу. Для цього в Python існують умовні
конструкції: `if`, `elif` та `else`.

```python-runner
score = 85

if score >= 90:
    print("Відмінно! Диплом першого ступеня.")
elif score >= 75:
    print("Чудово! Призове місце.")
else:
    print("Гарна спроба, продовжуй тренуватися!")
```

## Базова конструкція `if` та відступи

Синтаксис умови в Python дуже лаконічний: ключове слово `if`, вираз-умова і обов'язкова
**двокрапка `:`** у кінці рядка.

Команди, які мають виконатися за умови `True`, пишуться з **відступом у 4 пробіли**:

```python-runner
x = 10

if x > 0:
    print("Число додатне!")
    print(f"Його квадрат дорівнює {x * x}")

print("Цей рядок надрукується завжди, бо він поза блоком if.")
```

!!! important "Відступи визначають структуру коду"

    У мовах C++ чи Java блоки коду огортаються фігурними дужками `{}`. У Python дужок немає — блок коду визначається **виключно величиною відступу** (за стандартом PEP 8 — 4 пробіли). Якщо відступ порушено, інтерпретатор видасть помилку `IndentationError`.

## Повна форма: `if ... else`

Коли треба виконати одну дію при істинності умови, а іншу — при хибності, використовують гілку `else`:

```python-runner
password = "supersecret"
user_attempt = "wrong_password"

if user_attempt == password:
    print("Вхід дозволено!")
else:
    print("Невірний пароль! Спробуйте ще раз.")
```

Рівно один із двох блоків обов'язково виконається.

## Багатоваріантний вибір: `if ... elif ... else`

Якщо варіантів розвитку подій більше двох, на допомогу приходить конструкція `elif` (скорочення від *else if*). Ви можете додавати скільки завгодно блоків `elif`:

```python-runner
temp = 22

if temp < 0:
    weather = "Мороз"
elif temp < 15:
    weather = "Прохолодно"
elif temp < 28:
    weather = "Комфортно"
else:
    weather = "Спека"

print(f"Погода за вікном: {weather}")
```

### Як це працює:
1. Python перевіряє умови **по черзі зверху вниз**.
2. Щойно знайдено першу умову, яка дає `True`, виконується відповідний блок коду.
3. Усі наступні гілки `elif` та `else` **пропускаються**, навіть якщо їхні умови теж були б істинними!
4. Якщо жодна умова не справдилася — спрацьовує фінальний блок `else` (якщо він є).

## Вкладені умови

Умови можна вкладати одна в одну, збільшуючи відступ ще на 4 пробіли:

```python-runner
x = 12

if x > 0:
    if x % 2 == 0:
        print("x — додатне парне число")
    else:
        print("x — додатне непарне число")
```

Однак часто вкладені умови можна замінити одним `if` за допомогою логічних операторів `and` або `or`:

```python-runner
x = 12
if x > 0 and x % 2 == 0:
    print("x — додатне парне число")
```

## Тернарний умовний оператор

Якщо потрібно обрати одне з двох значень залежно від умови й одразу записати результат у змінну, використовують компактний умовний вираз:

$$\text{значення\_якщо\_True} \quad \mathbf{if} \quad \text{умова} \quad \mathbf{else} \quad \text{значення\_якщо\_False}$$

```python-runner
a = 15
b = 20

# Обираємо більше з двох чисел в один рядок
maximum = a if a > b else b
print("Більше число:", maximum)

# Інший приклад: статус парності
n = 7
status = "парне" if n % 2 == 0 else "непарне"
print(f"Число {n} — {status}")
```

## Truthy та Falsy: що Python вважає істиною?

У Python будь-який об'єкт або значення можна підставити в умову `if`. Python автоматично оцінює його як логічне значення:

**Вважаються брехнею (Falsy):**
- число `0`, `0.0`
- порожній рядок `""`
- `None`
- логічне `False`
- порожні колекції: `[]`, `{}`, `set()`

**Вважається істиною (Truthy):**
- Будь-яке ненульове число (наприклад, `42`, `-1`, `3.14`)
- Непорожній рядок (навіть рядок з одним пробілом `" "`)
- Непорожні списки та інші колекції

```python-runner
username = "Богдан"
# Замість if username != "":
if username:
    print(f"Користувач авторизований: {username}")

items_count = 0
if not items_count:
    print("Кошик покупок порожній!")
```

## Де? Як? Коли?

### 🌍 Де це використовується в реальному світі?

- **Авторизація та безпека**: перевірка чи співпадає пароль, чи користувач адміністратор, чи не заблокований акаунт.
- **Ігрова логіка**: чи закінчилися очки життя персонажа, чи відбулося зіткнення (`if player.x == enemy.x`).
- **Олімпіади**:
    - Обробка граничних випадків (edge cases): $n = 0$, від'ємні числа, порожні вхідні дані.
    - Визначення координатної чверті, порівняння кількох чисел.
    - Симуляція правил гри за умовою задачі.

### ⚙️ Як це працює в Python?

- Блоки коду парсяться на етапі створення абстрактного синтаксичного дерева (AST) за відступами.
- Завдяки концепції *short-circuit evaluation* (короткого замикання) у складній умові `if b != 0 and a // b > 2:` друга частина ніколи не викликатиме `ZeroDivisionError`, якщо `b == 0`, бо `b != 0` одразу дає `False`.

### 🎯 Коли обирати / застосовувати?

- Дві взаємовиключні дії $\rightarrow$ класичний `if ... else`.
- Більше двох альтернатив, де має спрацювати лише одна $\rightarrow$ ланцюжок `if ... elif ... else`.
- Просте обчислення або вибір значення $\rightarrow$ тернарний оператор `val = x if cond else y`.
- Перевірка непорожнього рядка чи числа $\rightarrow$ пиши лаконічно `if s:` замість `if len(s) > 0:`.

## Типові помилки

!!! danger "Забута двокрапка `:`"

    Одна з найпоширеніших механічних помилок у початківців — пропустити `:` у кінці рядка `if`, `elif` або `else`.

```python
# ❌ SyntaxError
# if x > 0
#     print("Додатне")

# ✅ Правильно
if x > 0:
    print("Додатне")
```

!!! danger "Кілька окремих `if` замість `elif`"

    Якщо написати кілька `if` підряд, комп'ютер перевірить **кожен з них**, навіть якщо перший вже спрацював! Це може зіпсувати логіку.

```python-runner
x = 15

# ❌ Помилка: надрукує обидва повідомлення!
if x > 10:
    print("Більше за 10")
if x > 5:
    print("Більше за 5")

# ✅ Правильно: виконається тільки перша гілка
if x > 10:
    print("Тільки більше за 10")
elif x > 5:
    print("Тільки більше за 5")
```

!!! danger "Надмірне `if x == True:`"

    Булеві змінні вже самі по собі є `True` або `False`. Дописувати `== True` не лише зайве, але й вважається поганим тоном у спільноті Python.

```python-runner
is_winner = True

# ❌ Не рекомендовано
if is_winner == True:
    print("Перемога!")

# ✅ Чистий Python-стиль
if is_winner:
    print("Перемога!")
```

### Задача 1. Парне чи непарне (Easy)

Дано ціле число $n$. Виведи слово `EVEN`, якщо число парне, і слово `ODD`, якщо число непарне.

Зверни увагу: число може бути нулем або від'ємним!

**Вхід:** одне ціле число $n$ ($-10^9 \le n \le 10^9$).
**Вихід:** `EVEN` або `ODD`.
**Приклад:** `input: "4" → output: "EVEN"`

Спробуй сам:

```task-runner {data-task-id="parity"}
# Зчитай число n і виведи EVEN або ODD
```

??? hint "Підказка"

    Число є парним, якщо остача від його ділення на 2 дорівнює нулю: `n % 2 == 0`.

??? success "Розв'язок"

    ```python-runner
    n = int(input())
    if n % 2 == 0:
        print("EVEN")
    else:
        print("ODD")
    ```

- `POSITIVE`, якщо $x > 0$
- `NEGATIVE`, якщо $x < 0$
- `ZERO`, якщо $x = 0$

**Вхід:** одне ціле число $x$ ($-10^9 \le x \le 10^9$).
**Вихід:** одне зі слів: `POSITIVE`, `NEGATIVE`, `ZERO`.
**Приклад:** `input: "15" → output: "POSITIVE"`

### Задача 3. Більше з двох чисел (Easy)

В одному рядку через пробіл подано два цілих числа $a$ та $b$. Виведи більше з них. Якщо числа однакові, виведи будь-яке з них.

Спробуй розв'язати задачу за допомогою конструкції `if` (без використання вбудованої функції `max`).

**Вхід:** два цілих числа $a$ і $b$ в одному рядку через пробіл ($-10^9 \le a, b \le 10^9$).
**Вихід:** одне число — найбільше з двох.
**Приклад:** `input: "5 9" → output: "9"`

Спробуй сам:

```task-runner {data-task-id="max-of-two"}
# Зчитай a і b, знайди більше з них за допомогою if
```

??? hint "Підказка"

    Зчитай числа через `a, b = map(int, input().split())`. Якщо `a > b`, виведи `a`, інакше виведи `b`.
    Також можна використати тернарний оператор: `print(a if a > b else b)`.

??? success "Розв'язок"

    ```python-runner
    a, b = map(int, input().split())
    if a > b:
        print(a)
    else:
        print(b)
    ```

### Задача 4. Колір клітинки шахівниці (Medium)

Шахівниця має розмір $8 \times 8$. Кожна клітинка задається двома координатами $(x, y)$, де $x$ — номер стовпця ($1 \le x \le 8$), а $y$ — номер рядка ($1 \le y \le 8$).

Відомо, що ліва нижня клітинка з координатами $(1, 1)$ має **чорний колір**.
Визнач колір клітинки із заданими координатами $(x, y)$. Якщо клітинка чорна — виведи `BLACK`, якщо біла — виведи `WHITE`.

**Вхід:** два числа $x$ і $y$ через пробіл в одному рядку.
**Вихід:** `BLACK` або `WHITE`.
**Приклад:** `input: "1 1" → output: "BLACK"`

Спробуй сам:

```task-runner {data-task-id="chess-color"}
# Зчитай x та y і визнач колір клітинки (BLACK чи WHITE)
```

??? hint "Підказка"

    Поглянь на шахівницю: клітинки $(1, 1)$, $(1, 3)$, $(2, 2)$, $(3, 1)$ — чорні. Що спільного мають їхні координати?
    Сума координат $x + y$ для чорних клітинок завжди парна ($1+1=2$, $2+2=4$), а для білих — непарна ($1+2=3$).

??? success "Розв'язок"

    ```python-runner
    x, y = map(int, input().split())
    if (x + y) % 2 == 0:
        print("BLACK")
    else:
        print("WHITE")
    ```
