# Цикли

Комп'ютери створені для того, щоб блискавично виконувати мільйони одноманітних операцій.
Якщо вам потрібно надрукувати числа від 1 до 1000 або перевірити всі дільники числа,
ви не пишете тисячу рядків коду — ви використовуєте **цикли**. У Python є два основних
види циклів: `while` (поки виконується умова) та `for` (перебір елементів послідовності).

```python-runner
# Цикл for перебирає числа від 1 до 5
for i in range(1, 6):
    print(f"Крок {i}: квадрат = {i * i}")
```

## Цикл `while`: повторення за умовою

Цикл `while` виконує блок команд доти, доки його умова залишається істинною (`True`):

```python-runner
count = 3

while count > 0:
    print(f"Зворотний відлік: {count}")
    count -= 1  # зменшуємо лічильник

print("Пуск! 🚀")
```

Перед кожним повторенням (ітерацією) Python перевіряє умову:
- якщо умова `True` $\rightarrow$ виконується тіло циклу;
- якщо умова `False` $\rightarrow$ цикл завершується, програма рухається далі.

!!! danger "Обережно: нескінченний цикл!"

    Якщо умова `while` ніколи не стає `False` (наприклад, ви забули змінити лічильник `count`), програма зависне назавжди. Завжди переконуйтеся, що всередині циклу є дія, яка наближає завершення умови!

## Цикл `for` та генератор діапазонів `range()`

Цикл `for` у Python працює як цикл перебору (*for-each*). Він бере по черзі елементи
з будь-якої послідовності. Найчастіше для повторення задану кількість разів
використовують функцію `range()`.

Функція `range()` має три форми виклику:

| Форма | Опис | Приклад | Згенеровані числа |
|---|---|---|---|
| `range(stop)` | Від `0` до `stop - 1` | `range(4)` | `0, 1, 2, 3` |
| `range(start, stop)` | Від `start` до `stop - 1` | `range(2, 6)` | `2, 3, 4, 5` |
| `range(start, stop, step)` | З кроком `step` | `range(1, 10, 2)` | `1, 3, 5, 7, 9` |

!!! warning "Права межа не включається!"

    Число `stop` **ніколи не входить** у діапазон! Якщо вам потрібні числа від $1$ до $N$ включно, завжди пишіть `range(1, n + 1)`.

```python-runner
# Прямий порядок з кроком 3:
print("Крок 3:", list(range(0, 15, 3)))

# Зворотний порядок з від'ємним кроком:
for i in range(5, 0, -1):
    print(i, end=" ")
print()
```

Цикл `for` вміє перебирати не лише числа, а й символи рядка:

```python-runner
word = "Олімп"
for letter in word:
    print(f"Символ: {letter}")
```

## Керування циклом: `break` та `continue`

Іноді поведінку циклу треба змінити на льоту:

- `break` — **негайно зупиняє цикл** і виходить з нього.
- `continue` — **пропускає решту поточної ітерації** і одразу переходить до наступного кроку.

```python-runner
# Приклад break: зупиняємось, коли знайшли число 7
for x in range(1, 20):
    if x == 7:
        print(f"Знайшли {x}! Зупиняємо пошук.")
        break
    print(x, end=" ")
print()

# Приклад continue: друкуємо лише непарні числа, пропускаючи парні
for x in range(1, 10):
    if x % 2 == 0:
        continue  # пропускаємо парні
    print(f"Непарне: {x}")
```

## Блок `else` у циклах: родзинка Python

У Python цикли можуть мати власний блок `else`! Код у блоці `else` виконується лише тоді, коли цикл **завершився природно** (вичерпав діапазон або умова `while` стала `False`), і **не виконується**, якщо цикл було перервано командою `break`.

Це неймовірно зручно для задач пошуку:

```python-runner
target = 13
numbers = [2, 4, 6, 8, 10]

for n in numbers:
    if n == target:
        print(f"Знайдено число {target}!")
        break
else:
    # Виконається тільки якщо break ЖОДНОГО разу не спрацював
    print(f"Число {target} у списку відсутнє.")
```

## Вкладені цикли

Один цикл можна помістити всередину іншого. Наприклад, щоб надрукувати прямокутну таблицю або обійти клітинки сітки:

```python-runner
# Таблиця множення 3x3:
for i in range(1, 4):
    for j in range(1, 4):
        print(f"{i * j:2d}", end=" ")
    print()  # перехід на новий рядок після кожного рядка таблиці
```

## Де? Як? Коли?

### 🌍 Де це використовується в реальному світі?

- **Обробка великих масивів**: обчислення середнього чека клієнтів, аналіз сенсорних даних кожну мілісекунду.
- **Ігрові рушії**: нескінченний головний цикл гри `while running:`, який 60 разів на секунду оновлює фізику й малює кадр.
- **Олімпіади**:
    - **Повний перебір (brute force)**: коли треба перевірити всі можливі варіанти відповіді.
    - **Алгоритм Евкліда**: швидкий пошук найбільшого спільного дільника (НСД) через `while b > 0:`.
    - **Розбиття числа на цифри**: доки `n > 0`, беремо цифру `n % 10` та відкидаємо `n //= 10`.

### ⚙️ Як це працює в Python?

- Об'єкт `range` не створює всі числа в пам'яті одночасно! `range(10**18)` займає всього кілька байт пам'яті, генеруючи наступне число лише за потреби.
- Цикл `for` у Python під капотом викликає функцію `iter()` над об'єктом, а на кожному кроці — функцію `next()`, доки не буде піднято сигнал `StopIteration`.

### 🎯 Коли обирати `for`, а коли `while`?

- Відома кількість повторень або є готова послідовність / діапазон $\rightarrow$ **обирай `for`**.
- Кількість повторень наперед невідома, а завершення залежить від зміни значення змінних (наприклад, ділимо число, доки воно не стане нулем) $\rightarrow$ **обирай `while`**.
- Потрібно знайти перший елемент, що задовольняє умову $\rightarrow$ використовуй `for` + `if` + `break` + `else`.

## Типові помилки

!!! danger "Забута зміна змінної в циклі `while`"

    Якщо ви не змінюєте змінну всередині `while`, цикл виконуватиметься нескінченно, а програма перевищить ліміт часу (Time Limit Exceeded на олімпіаді).

```python
# ❌ Нескінченний цикл
# i = 1
# while i <= 5:
#     print(i)
#     # Забули i += 1!

# ✅ Правильно
i = 1
while i <= 5:
    print(i)
    i += 1
```

!!! danger "Помилка на одиницю (Off-by-one error)"

    Пам'ятай: `range(1, 5)` згенерує лише числа `1, 2, 3, 4`. Число `5` не буде опрацьоване!

```python-runner
# ❌ Помилка: обійде тільки числа від 1 до 4
total = 0
for i in range(1, 5):
    total += i
print("Сума до 4:", total)

# ✅ Правильно для чисел від 1 до 5 включно:
total = 0
for i in range(1, 6):
    total += i
print("Сума до 5:", total)
```

!!! danger "`break` у вкладеному циклі"

    Команда `break` перериває **лише той цикл, всередині якого вона безпосередньо знаходиться**. Зовнішній цикл продовжить свою роботу.

### Задача 1. Сума чисел від 1 до N (Easy)

Дано натуральне число $N$. Знайди суму всіх цілих чисел від $1$ до $N$ включно:
$$S = 1 + 2 + 3 + \dots + N$$

**Вхід:** одне натуральне число $N$ ($1 \le N \le 10^4$).
**Вихід:** одне число — сума від $1$ до $N$.
**Приклад:** `input: "5" → output: "15"` ($1 + 2 + 3 + 4 + 5 = 15$)

Спробуй сам:

```task-runner {data-task-id="sum-n"}
# Зчитай N і обчисли суму чисел від 1 до N за допомогою циклу
```

??? hint "Підказка"

    Заведи змінну-акумулятор `total = 0` і за допомогою циклу `for i in range(1, n + 1):` додавай `i` до `total`.

??? success "Розв'язок"

    ```python-runner
    n = int(input())
    total = 0
    for i in range(1, n + 1):
        total += i
    print(total)
    ```

### Задача 2. Факторіал числа (Easy)

Дано ціле число $n$. Обчисли його факторіал $n!$:
$$n! = 1 \cdot 2 \cdot 3 \dots \cdot n$$
За математичним означенням, факторіал нуля дорівнює одиниці: $0! = 1$.

**Вхід:** одне ціле число $n$ ($0 \le n \le 12$).
**Вихід:** одне число — значення $n!$.
**Приклад:** `input: "5" → output: "120"`

Спробуй сам:

```task-runner {data-task-id="factorial"}
# Обчисли факторіал числа n
```

??? hint "Підказка"

    Почни зі змінної `fact = 1`. Якщо $n > 0$, у циклі `for i in range(1, n + 1):` множ `fact *= i`. Для $n = 0$ цикл просто не виконається жодного разу, і `fact` залишиться рівним `1`.

??? success "Розв'язок"

    ```python-runner
    n = int(input())
    fact = 1
    for i in range(1, n + 1):
        fact *= i
    print(fact)
    ```

### Задача 3. Кількість нулів (Medium)

У першому рядку задано число $N$ — кількість чисел, які будуть введені далі.
У наступних $N$ рядках введено по одному цілому числу.
Порахуй і виведи, скільки серед цих чисел було нулів.

**Вхід:** у першому рядку натуральне число $N$ ($1 \le N \le 1000$). У наступних $N$ рядках — по одному цілому числу.
**Вихід:** одне число — кількість введених нулів.
**Приклад:** `input: "5\n1\n0\n5\n0\n3" → output: "2"`

Спробуй сам:

```task-runner {data-task-id="count-zeros"}
# Зчитай N чисел і порахуй, скільки серед них дорівнюють нулю
```

??? hint "Підказка"

    Зчитай $N$ за допомогою `n = int(input())`. Створи лічильник `zeros = 0`.
    Запусти цикл `for _ in range(n):`, у якому на кожному кроці зчитуй чергове число `val = int(input())` і, якщо `val == 0`, збільшуй лічильник.

??? success "Розв'язок"

    ```python-runner
    n = int(input())
    zeros = 0
    for _ in range(n):
        val = int(input())
        if val == 0:
            zeros += 1
    print(zeros)
    ```

### Задача 4. Алгоритм Евкліда (НСД) (Medium)

Дано два натуральних числа $a$ та $b$ в одному рядку через пробіл. Знайди їхній **найбільший спільний дільник (НСД)**.

Використай швидкий алгоритм Евкліда за допомогою циклу `while`:
Поки $b \ne 0$, замінюємо пару $(a, b)$ на $(b, a \pmod b)$. Коли $b$ стане рівним $0$, відповіддю буде $a$.

**Вхід:** два натуральних числа $a$ і $b$ через пробіл ($1 \le a, b \le 10^9$).
**Вихід:** одне число — НСД чисел $a$ та $b$.
**Приклад:** `input: "12 18" → output: "6"`

Спробуй сам:

```task-runner {data-task-id="gcd"}
# Реалізуй алгоритм Евкліда через цикл while
```

??? hint "Підказка"

    У Python можна міняти змінні в один рядок:
    ```python
    while b > 0:
        a, b = b, a % b
    print(a)
    ```

??? success "Розв'язок"

    ```python-runner
    a, b = map(int, input().split())
    while b > 0:
        a, b = b, a % b
    print(a)
    ```
