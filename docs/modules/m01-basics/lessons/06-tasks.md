## Змінні та арифметика

!!! task "Задача 1. Сума цифр (Easy)"

    Зчитай одне ціле число `n` (0 ≤ n ≤ 10⁹) і виведи суму його цифр.

    **Вхід:** одне ціле число.
    **Вихід:** одне число — сума цифр.
    **Приклад:** `input: "123" → output: "6"`

    Спробуй сам:

    ```task-runner {data-task-id="sum-digits"}
    # Зчитай число і виведи суму його цифр
    ```

    ??? hint "Підказка"

        Перетвори число на рядок через `str(n)` і пройдись по символах,
        перетворюючи кожен назад на число через `int(d)`.

    ??? success "Розв'язок"

        ```python-runner
        n = input()
        print(sum(int(d) for d in n))
        ```

!!! task "Задача 2. Максимум з трьох (Easy)"

    Зчитай три цілих числа в одному рядку через пробіл і виведи
    найбільше з них.

    **Вхід:** три числа через пробіл.
    **Вихід:** найбільше число.
    **Приклад:** `input: "1 2 3" → output: "3"`

    Спробуй сам:

    ```task-runner {data-task-id="max-three"}
    # Зчитай три числа і виведи найбільше
    ```

    ??? hint "Підказка"

        Використай вбудовану функцію `max(a, b, c)`.

    ??? success "Розв'язок"

        ```python-runner
        a, b, c = map(int, input().split())
        print(max(a, b, c))
        ```

!!! task "Задача 3. Кількість парних (Easy)"

    Зчитай числа в одному рядку через пробіл (може бути порожній рядок)
    і виведи кількість парних серед них.

    **Вхід:** числа через пробіл (рядок може бути порожнім).
    **Вихід:** одне число — кількість парних.
    **Приклад:** `input: "1 2 3 4 5 6" → output: "3"`

    Спробуй сам:

    ```task-runner {data-task-id="even-count"}
    # Порахуй парні числа у введенні
    ```

    ??? hint "Підказка"

        Перевір `x % 2 == 0` для кожного числа. Для порожнього рядка
        `split()` поверне порожній список — обробляй це окремо.

    ??? success "Розв'язок"

        ```python-runner
        line = input()
        nums = list(map(int, line.split())) if line else []
        print(sum(1 for x in nums if x % 2 == 0))
        ```

!!! task "Задача 5. Перетворення температури (Medium)"

    Зчитай температуру в градусах Цельсія (ціле число) і виведи
    температуру в градусах Фаренгейта з точністю до 1 знака.

    Формула: $F = C \times \frac{9}{5} + 32$.

    **Вхід:** одне ціле число — градуси Цельсія.
    **Вихід:** одне число (дробове) — градуси Фаренгейта, з `1` знаком
    після коми.
    **Приклад:** `input: "0" → output: "32.0"`

    Спробуй сам:

    ```task-runner {data-task-id="temp-convert"}
    # Перетвори Цельсій у Фаренгейт
    ```

    ??? hint "Підказка"

        Використай `f"{value:.1f}"` для форматування з 1 знаком після
        коми.

    ??? success "Розв'язок"

        ```python-runner
        f = c * 9 / 5 + 32
        print(f"{f:.1f}")
        ```

!!! task "Задача 6. Високосний рік (Medium)"

    Зчитай рік `y` (1 ≤ y ≤ 9999) і виведи `YES`, якщо рік високосний,
    і `NO` інакше.

    Рік високосний, якщо:
    - ділиться на 4, **і**
    - **не** ділиться на 100, **або** ділиться на 400.

    **Вхід:** одне ціле число — рік.
    **Вихід:** `YES` або `NO`.
    **Приклад:** `input: "2000" → output: "YES"` (ділиться на 400)

    Спробуй сам:

    ```task-runner {data-task-id="leap-year"}
    # Визнач, чи є рік високосним
    ```

    ??? hint "Підказка"

        Запиши умову один раз через `and`/`or`, без вкладених `if`.

    ??? success "Розв'язок"

        ```python-runner
        y = int(input())
        print("YES" if (y % 4 == 0 and y % 100 != 0) or y % 400 == 0 else "NO")
        ```

## Цикли

!!! task "Задача 7. Усі дільники (Medium)"

    Зчитай ціле число `n` (1 ≤ n ≤ 10⁶) і виведи через пробіл усі його
    дільники в порядку зростання.

    **Вхід:** одне ціле число.
    **Вихід:** дільники через пробіл.
    **Приклад:** `input: "12" → output: "1 2 3 4 6 12"`

    Спробуй сам:

    ```task-runner {data-task-id="divisors"}
    # Виведи всі дільники числа
    ```

    ??? hint "Підказка"

        Дільники йдуть парами: якщо `i` ділить `n`, то `n // i` теж.
        Досить перебрати `i` до `√n`.

    ??? success "Розв'язок"

        ```python-runner
        n = int(input())
        small = [i for i in range(1, int(n**0.5) + 1) if n % i == 0]
        large = [n // i for i in reversed(small) if i * i != n]
        print(" ".join(map(str, sorted(small + large))))
        ```
