# Модуль 2. Колекції

Колекції — це спосіб зберігати **кілька значень в одній змінній**. У Python
є чотири базові колекції, і кожна має свої сильні сторони.

## Уроки

1. **Рядки** — індексація, зрізи, методи
2. **Списки** — динамічні масиви, додавання, видалення
3. **Кортежі** — незмінювані послідовності
4. **Словники** — пари ключ-значення, швидкий пошук
5. **Множини** — унікальні елементи, теорія множин
6. **Задачі модуля 2** — практика на колекції

## Після модуля ви зможете

- [x] обирати правильну колекцію під задачу
- [x] ефективно працювати з рядками (пошук, заміна, форматування)
- [x] використовувати словники для підрахунку й групування
- [x] розв'язувати задачі на масиви та множини
