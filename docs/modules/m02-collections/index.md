# Модуль 2. Колекції

Колекції — це спосіб зберігати та ефективно обробляти **групи значень в одній змінній**. В олімпіадному програмуванні правильний вибір колекції часто вирішує долю розв'язку: чи вкладеться програма в обмеження 1 секунди, чи отримає Time Limit Exceeded.

У цьому модулі ми детально розберемо п'ять головних колекцій Python: рядки, списки, кортежі, словники та множини.

## Уроки

1. [Рядки](lessons/01-strings.md) — незмінювані послідовності символів, зрізи, методи `split`, `join`, пошук та заміна
2. [Списки](lessons/02-lists.md) — динамічні масиви, операції додавання/видалення, сортування, спискові включення, матриці
3. [Кортежі](lessons/03-tuples.md) — незмінювані послідовності, розпакування кортежів, `zip()`, `enumerate()`, лексикографічне сортування
4. [Словники](lessons/04-dicts.md) — хеш-таблиці, пари ключ-значення, пошук за $O(1)$, частотний аналіз, `Counter`, `defaultdict`
5. [Множини](lessons/05-sets.md) — унікальні елементи, операції теорії множин (перетин, об'єднання, різниця), миттєва перевірка входження
6. [Задачі модуля 2](lessons/06-tasks.md) — олімпіадна практика на весь матеріал модуля

- [x] віртуозно використовувати списки та двовимірні масиви
