# Рядки

Рядок у Python — це впорядкована послідовність символів типу `str`. Майже в кожній олімпіадній задачі вхідні дані надходять у вигляді тексту: числа, розділені пробілами, слова, координати чи шифровані повідомлення.

Головна особливість рядків у Python — вони **незмінювані** (*immutable*). Створений рядок не можна змінити «на місці», але за допомогою зрізів та десятків вбудованих методів можна миттєво конструювати нові рядки.

```python-runner
# Створення рядків і робота з ними
greeting = "Привіт, Олімпіадо!"
print("Довжина рядка:", len(greeting))
print("Перший символ:", greeting[0])
print("Останній символ:", greeting[-1])
print("У верхньому регістрі:", greeting.upper())
```

## Індексація: доступ до окремих символів

Кожен символ у рядку має свій числовий номер — **індекс**. У Python індексація починається з `0`.

Також підтримується **від'ємна індексація**, де `-1` — це останній символ, `-2` — передостанній і так далі:

```
 Символ:   P   y   t   h   o   n
 Індекс:   0   1   2   3   4   5
 Від'ємн: -6  -5  -4  -3  -2  -1
```

```python-runner
s = "Python"
print("s[0] =", s[0])    # P
print("s[2] =", s[2])    # t
print("s[-1] =", s[-1])  # n
print("s[-3] =", s[-3])  # h
```

!!! danger "Помилка IndexError"

    Спроба звернутися за індексом, якого не існує (наприклад, `s[10]` для рядка з 6 символів), викличе помилку `IndexError: string index out of range`.

## Зрізи (Slices): витягування підрядків

Зрізи дозволяють отримати будь-яку частину рядка за формулою:

$$
\text{рядок}[\text{start} : \text{stop} : \text{step}]
$$

- `start` — індекс початку (включається, за замовчуванням `0`).
- `stop` — індекс кінця (**не включається**, за замовчуванням кінець рядка).
- `step` — крок (за замовчуванням `1`, може бути від'ємним).

```python-runner
text = "Олімпіада"

print("text[0:5]   ->", text[0:5])    # Олімп (символи 0, 1, 2, 3, 4)
print("text[:5]    ->", text[:5])     # перші 5 символів
print("text[5:]    ->", text[5:])     # від 5-го індексу до кінця
print("text[::2]   ->", text[::2])    # кожен 2-й символ
print("text[::-1]  ->", text[::-1])   # розворот рядка задом наперед!
```

!!! tip "Зрізи ніколи не падають з IndexError"

    На відміну від прямої індексації `s[100]`, зріз `s[0:100]` не викликає помилки. Python автоматично обмежить зріз реальною довжиною рядка.

## Незмінюваність рядків (Immutability)

Рядок не можна змінити посимвольно:

```python-runner
word = "кіт"
# word[0] = "к" — викличе TypeError!
# Щоб "змінити" символ, утворюємо новий рядок:
new_word = "л" + word[1:]
print(new_word)  # літ
```

## Найважливіші методи рядків

Рядки мають багатий набір вбудованих методів. Оскільки рядки незмінювані, кожен метод повертає **новий рядок**, не змінюючи початковий.

### 1. Зміна регістру

```python-runner
msg = "Олімпіада з Інформатики"
print(msg.lower())       # олімпіада з інформатики
print(msg.upper())       # ОЛІМПІАДА З ІНФОРМАТИКИ
print(msg.capitalize())  # перша літера велика, решта маленькі
print(msg.title())       # Кожне Слово З Великої
```

### 2. Пошук та підрахунок

| Метод / Оператор | Опис | Що повертає, якщо немає |
|---|---|---|
| `x in s` | Перевірка наявності підрядка | `False` |
| `s.find(sub)` | Перший індекс входження зліва | `-1` |
| `s.rfind(sub)` | Останній індекс входження справа | `-1` |
| `s.index(sub)` | Перший індекс входження | Викидає `ValueError` |
| `s.count(sub)` | Кількість входжень підрядка | `0` |

```python-runner
phrase = "абракадабра"
print("Є 'кад'?", "кад" in phrase)
print("Індекс 'ра':", phrase.find("ра"))     # 2
print("Останній 'ра':", phrase.rfind("ра"))  # 9
print("Скільки букв 'а':", phrase.count("а")) # 5
print("Пошук 'xyz':", phrase.find("xyz"))    # -1
```

### 3. Очищення та заміна

- `strip()` — видаляє пробільні символи (пробіли, `\n`, `\t`) на початку та в кінці.
- `lstrip()` / `rstrip()` — очищення лише зліва або справа.
- `replace(old, new)` — замінює всі входження `old` на `new`.

```python-runner
raw = "   \n  олімпіада 2026   \t "
clean = raw.strip()
print(f"Було: '{raw}'")
print(f"Стало: '{clean}'")

formula = "1 + 2 + 3 + 4"
print(formula.replace("+", "*"))  # 1 * 2 * 3 * 4
```

### 4. Розбиття та збирання: `split()` та `join()`

Це два фундаментальних методи для олімпіадного введення та виведення:

- `s.split()` — розбиває рядок за пробілами на список слів.
- `s.split(sep)` — розбиває рядок за вказаним роздільником `sep`.
- `sep.join(iterable)` — об'єднує список рядків в один, вставляючи `sep` між ними.

```python-runner
# Розбиваємо вхідний рядок на окремі слова
line = "Київ Львів Харків Одеса"
cities = line.split()
print("Список міст:", cities)

# Збираємо назад через тире
result = " -> ".join(cities)
print("Маршрут:", result)
```

### 5. Перевірка символів

- `s.isdigit()` — чи складається рядок виключно з цифр.
- `s.isalpha()` — чи складається лише з літер.
- `s.isalnum()` — чи складається з літер та цифр.
- `s.startswith(prefix)` — чи починається з префікса.
- `s.endswith(suffix)` — чи закінчується суфіксом.

```python-runner
code = "42035"
print(code.isdigit())     # True
print("file.py".endswith(".py"))  # True
```

## Де? Як? Коли?

### 🌍 Де це використовується в реальному світі?

- **Парсинг та веб-скрейпінг**: розбір HTML, JSON, витягування URL-адрес та імен користувачів.
- **Обробка природної мови (NLP)**: токенізація текстів, аналіз тональності, переклад.
- **Безпека**: перевірка складності паролів, санітизація вхідних даних проти ін'єкцій.
- **Олімпіади**: 90% задач вимагають парсингу вхідного потоку, розбиття на лексеми через `split()`, перевірки на паліндроми та пошуку підрядків.

### ⚙️ Як це працює в Python?

- У CPython рядки зберігаються в неперервних блоках пам'яті. Залежно від символів (ASCII, 2-байтний або 4-байтний Unicode), Python оптимізує пам'ять (PEP 393), використовуючи 1, 2 або 4 байти на символ.
- Операція `s[::-1]` працює за $O(n)$ часу і створює новий рядок у пам'яті.
- Додавання рядків у циклі через `s += char` створює новий об'єкт на кожній ітерації і може сповільнити програму до $O(n^2)$. Для швидкої склейки завжди збирайте символи у список і робіть `"".join(chars)` — це працює за $O(n)$.

### 🎯 Коли обирати / застосовувати?

- **Потрібно перевернути рядок** $\rightarrow$ зріз `s[::-1]`.
- **Потрібно зчитати числа в рядку через пробіл** $\rightarrow$ `map(int, input().split())`.
- **Потрібно перевірити наявність слова** $\rightarrow$ `if word in text:`.
- **Потрібно видалити зайві перенесення рядків** $\rightarrow$ `s.strip()`.
- **Потрібно склеїти тисячі частин** $\rightarrow$ `"".join(parts)`.

## Типові помилки

!!! danger "Спроба змінити символ за індексом"

    Рядки не можна змінювати як масиви в C++ чи Pascal.

```python-runner
s = "привіт"
# s[0] = "П"   # ❌ TypeError: 'str' object does not support item assignment

# ✅ Правильно: створити новий рядок
s = "П" + s[1:]
print(s)
```

!!! danger "Забули зберегти результат виклику методу"

    Методи рядків не змінюють початкову змінну, вони повертають новий рядок!

```python-runner
name = "богдан"
name.upper()   # ❌ Результат загублено!
print(name)    # все ще "богдан"

name = name.upper()  # ✅ Правильно зберегли результат
print(name)          # "БОГДАН"
```

!!! danger "Плутанина між find() та index()"

    Якщо підрядок відсутній, `find()` поверне `-1`, а `index()` аварійно зупинить програму помилкою `ValueError`. Якщо ви не впевнені, чи є символ — використовуйте `in` або `find()`.

!!! task "Задача 1. Паліндром (Easy)"

    Рядок називається паліндромом, якщо він читається однаково зліва направо і справа наліво. Перевір, чи є задане слово паліндромом (без урахування регістру).

    **Вхід:** один рядок, що містить слово.
    **Вихід:** `YES`, якщо слово є паліндромом, і `NO` в іншому випадку.
    **Приклад:** `input: "Racecar" → output: "YES"`

    Спробуй сам:

    ```task-runner {data-task-id="palindrome"}
    # Зчитай рядок і виведи YES або NO
    ```

    ??? hint "Підказка"

        Переведи рядок у нижній регістр за допомогою `.lower()` і порівняй його зі своїм розворотом `s[::-1]`.

    ??? success "Розв'язок"

        ```python-runner
        s = input().strip().lower()
        if s == s[::-1]:
            print("YES")
        else:
            print("NO")
        ```

!!! task "Задача 2. Кількість голосних (Easy)"

    Порахуй кількість голосних літер (`a`, `e`, `i`, `o`, `u`, `y`) у вхідному рядку англійського тексту. Регістр літер не має значення.

    **Вхід:** один рядок тексту.
    **Вихід:** одне ціле число — кількість голосних.
    **Приклад:** `input: "hello world" → output: "3"`

    Спробуй сам:

    ```task-runner {data-task-id="count-vowels"}
    # Зчитай рядок і порахуй голосні
    ```

    ??? hint "Підказка"

        Переведи рядок у нижній регістр. Пройдися циклом `for char in s:` і перевір `if char in "aeiouy":`.

    ??? success "Розв'язок"

        ```python-runner
        s = input().strip().lower()
        vowels = "aeiouy"
        count = sum(1 for ch in s if ch in vowels)
        print(count)
        ```

!!! task "Задача 3. Зворотний порядок слів (Medium)"

    Дано речення, слова в якому відокремлені одним або кількома пробілами. Виведи всі слова у зворотному порядку, розділивши їх одним пробілом.

    **Вхід:** рядок зі словами.
    **Вихід:** рядок зі словами у зворотному порядку.
    **Приклад:** `input: "Hello World Python" → output: "Python World Hello"`

    Спробуй сам:

    ```task-runner {data-task-id="reverse-words"}
    # Зчитай речення і виведи слова задом наперед
    ```

    ??? hint "Підказка"

        Використай метод `.split()`, щоб отримати список слів, розверни його зрізом `[::-1]` і об'єднай назад за допомогою `" ".join(...)`.

    ??? success "Розв'язок"

        ```python-runner
        words = input().strip().split()
        print(" ".join(words[::-1]))
        ```

!!! task "Задача 4. Очищення зайвих пробілів (Medium)"

    **Вхід:** рядок з довільною кількістю пробілів.
    **Вихід:** очищений рядок.
    **Приклад:** `input: "  hello    world   from   python  " → output: "hello world from python"`

    Спробуй сам:

    ```task-runner {data-task-id="clean-spaces"}
    # Нормалізуй пробіли у рядку
    ```

    ??? hint "Підказка"

        Метод `split()` без аргументів автоматично групує всі послідовні пробільні символи в один роздільник і відкидає пробіли по краях.

    ??? success "Розв'язок"

        ```python-runner
        s = input().strip()
        words = s.split()
        print(" ".join(words))
        ```
