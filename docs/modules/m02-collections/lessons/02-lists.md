# Списки

Список (`list`) — це головна робоча конячка в Python. Це впорядкована колекція довільних елементів, яку можна змінювати: додавати нові значення, видаляти існуючі, переставляти та сортувати.

В інших мовах програмування подібні структури називають динамічними масивами (`vector` у C++, `ArrayList` у Java). В олімпіадах майже кожна задача зводиться до збереження чисел або об'єктів у списку та їх подальшої обробки.

```python-runner
# Створення та базові операції зі списком
numbers = [10, 20, 30, 40]
numbers.append(50)      # додаємо елемент у кінець
numbers[1] = 99         # змінюємо другий елемент
print("Список:", numbers)
print("Довжина:", len(numbers))
print("Сума:", sum(numbers))
```

## Створення та індексація

Списки записуються у квадратних дужках `[...]`, а елементи відокремлюються комами:

```python-runner
empty = []                    # порожній список
zeros = [0] * 5               # [0, 0, 0, 0, 0]
mixed = [1, "два", 3.0, True] # елементи різних типів

print("zeros:", zeros)
print("mixed[1]:", mixed[1])
print("mixed[-1]:", mixed[-1])  # останній елемент
```

Зрізи для списків працюють точнісінько так само, як і для рядків:

```python-runner
nums = [0, 1, 2, 3, 4, 5, 6, 7]
print("nums[2:5]  ->", nums[2:5])   # [2, 3, 4]
print("nums[:3]   ->", nums[:3])    # [0, 1, 2]
print("nums[::2]  ->", nums[::2])   # [0, 2, 4, 6]
print("nums[::-1] ->", nums[::-1])  # розвернутий список
```

## Додавання та видалення елементів

У таблиці наведено методи зміни списку та їхня обчислювальна складність:

| Метод | Що робить | Складність |
|---|---|---|
| `lst.append(x)` | Додає `x` у кінець списку | $O(1)$ |
| `lst.extend(iterable)` | Додає всі елементи іншої колекції | $O(k)$ |
| `lst.insert(i, x)` | Вставляє `x` на позицію `i` | $O(n)$ |
| `lst.pop()` | Видаляє і повертає **останній** елемент | $O(1)$ |
| `lst.pop(i)` | Видаляє і повертає елемент за індексом `i` | $O(n)$ |
| `lst.remove(x)` | Видаляє **перше** входження значення `x` | $O(n)$ |
| `lst.clear()` | Очищає весь список | $O(1)$ |

```python-runner
stack = []
stack.append(10)
stack.append(20)
stack.append(30)
print("Після append:", stack)

last = stack.pop()
print(f"Витягнули {last}, залишилось:", stack)

stack.insert(0, 999)  # вставка на початок
print("Після insert(0, 999):", stack)
```

!!! warning "Чому insert(0, x) та pop(0) повільні?"

    Список зберігається у неперервному блоці пам'яті. Якщо ви додаєте або видаляєте елемент на початку (`index = 0`), Python змушений зсунути всі інші $n-1$ елементів. Якщо викликати це в циклі $n$ разів, програма отримає $O(n^2)$ і в олімпіадній задачі трапиться Time Limit Exceeded (TLE).

## Пошук, підрахунок та сортування

```python-runner
arr = [5, 2, 8, 2, 1, 9]

print("Мінімум:", min(arr))
print("Максимум:", max(arr))
print("Сума:", sum(arr))
print("Скільки двійок:", arr.count(2))
print("Індекс числа 8:", arr.index(8))

# Сортування двома способами:
sorted_copy = sorted(arr)   # створює новий відсортований список
print("sorted():", sorted_copy)
print("Оригінал не змінився:", arr)

arr.sort()                  # сортує список на місці (in-place)
print("Після arr.sort():", arr)

arr.sort(reverse=True)      # сортування за спаданням
print("За спаданням:", arr)
```

## Спискові включення (List Comprehensions)

Спискові включення — це швидкий та елегантний спосіб створення списків у Python. Вони працюють значно швидше, ніж ручне додавання через `for` та `append()`.

Синтаксис:

$$
[\text{вираз} \textbf{ for } \text{змінна} \textbf{ in } \text{послідовність} \textbf{ if } \text{умова}]
$$

```python-runner
# Квадрати чисел від 1 до 5
squares = [x * x for x in range(1, 6)]
print("Квадрати:", squares)

# Тільки парні числа
evens = [x for x in range(1, 11) if x % 2 == 0]
print("Парні:", evens)

# Зчитування масиву чисел з одного рядка
raw_input = "15 42 7 -3 99"
numbers = [int(x) for x in raw_input.split()]
print("Зчитані числа:", numbers)
```

## Двовимірні списки (Матриці)

Матриця в Python представляється як список списків:

```python-runner
# Матриця 3x3
matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]

# Доступ: matrix[рядок][стовпчик]
print("Елемент у рядку 1, стовпчику 2:", matrix[1][2])  # 6
```

### Як правильно створювати матрицю $N \times M$

```python-runner
rows, cols = 3, 4

# ✅ ПРАВИЛЬНО: кожен рядок — новий незалежний список
grid = [[0] * cols for _ in range(rows)]
grid[0][0] = 99
print("Правильна матриця:")
for r in grid:
    print(r)
```

## Де? Як? Коли?

### 🌍 Де це використовується в реальному світі?

- **Бази даних та бекенд**: списки товарів, користувачів, повідомлень у стрічці.
- **Геймдев**: інвентар гравця, координати ворогів на карті, черга подій.
- **Машинне навчання**: вектори ознак, списки передбачень класифікатора.
- **Олімпіади**: збереження масиву вхідних даних, динамічне програмування (таблиці DP), списки суміжності графів.

### ⚙️ Як це працює в Python?

- Список у CPython — це масив вказівників на об'єкти із надлишковим виділенням пам'яті (*over-allocation*). При вичерпанні буфера Python автоматично виділяє пам'ять із запасом (приблизно в 1.125 раза більше), тому середня амортизована складність `append()` становить $O(1)$.
- Сортування `sort()` та `sorted()` використовує алгоритм **Timsort** (гібрид сортування злиттям та вставками), який працює за $O(n \log n)$ у найгіршому випадку та $O(n)$ на частково відсортованих даних.

### 🎯 Коли обирати / застосовувати?

- **Потрібен доступ за числовим індексом** $\rightarrow$ `list`.
- **Потрібно часто додавати елементи в кінець** $\rightarrow$ `lst.append()`.
- **Потрібно часто видаляти/додавати елементи з початку** $\rightarrow$ замість списку краще використати `collections.deque` ($O(1)$ замість $O(n)$).
- **Потрібно перевіряти наявність елемента (`x in collection`) серед мільйона значень** $\rightarrow$ `set` або `dict`, оскільки у списку це займе $O(n)$.

## Типові помилки

!!! danger "Пастка створення матриці через множення: [[0] * m] * n"

    Це одна з найпідступніших помилок початківців!

```python-runner
# ❌ НЕПРАВИЛЬНО:
bad_matrix = [[0] * 3] * 3
bad_matrix[0][0] = 777

# Змінився не лише перший рядок, а ВСІ рядки одразу!
print("Зламана матриця:")
for row in bad_matrix:
    print(row)
```

Чому це сталося? Множення `[[0] * 3] * 3` створило список із трьох **посилань на один і той самий рядок** у пам'яті. Завжди використовуйте генератор: `[[0] * m for _ in range(n)]`.

!!! danger "Копіювання посилання замість копіювання списку"

```python-runner
a = [1, 2, 3]
b = a          # ❌ b і a посилаються на один і той самий список!
b.append(4)
print("a:", a) # [1, 2, 3, 4] — список 'a' теж змінився!

# ✅ ПРАВИЛЬНО: копіювати через .copy() або зріз [:]
a = [1, 2, 3]
b = a.copy()
b.append(4)
print("a після правильної копії:", a) # [1, 2, 3]
```

!!! danger "Зміна списку під час ітерації по ньому"

    Ніколи не видаляйте елементи зі списку циклом `for x in lst: lst.remove(x)`. Це збиває внутрішній лічильник циклу, і частина елементів буде пропущена. Використовуйте спискове включення: `lst = [x for x in lst if condition]`.

!!! task "Задача 1. Другий за величиною елемент (Easy)"

    Дано ціле число $N$ ($N \ge 2$) та список із $N$ цілих чисел. Знайди **друге за величиною число** (тобто строго менше за максимальне число серед заданих).

    **Вхід:** перший рядок — число $N$. Другий рядок — $N$ чисел через пробіл. Гарантується, що є принаймні два різних числа.
    **Вихід:** одне число — другий максимум.
    **Приклад:**
    ```
    input:
    5
    1 5 2 4 3
    output: 4
    ```

    Спробуй сам:

    ```task-runner {data-task-id="second-largest"}
    # Знайди другий максимум у списку
    ```

    ??? hint "Підказка"

        Перетвори список на множину `set()`, щоб прибрати дублікати, відсортуй отримані унікальні числа і візьми передостаннє: `sorted(set(nums))[-2]`.

    ??? success "Розв'язок"

        ```python-runner
        n = int(input())
        nums = [int(x) for x in input().split()]
        unique_sorted = sorted(set(nums))
        print(unique_sorted[-2])
        ```

!!! task "Задача 2. Циклічний зсув масиву (Easy)"

    Дано список цілих чисел. Зроби циклічний зсув елементів списку праворуч на одну позицію: останній елемент стає першим, а всі інші зсуваються на один індекс вправо.

    **Вхід:** один рядок із числами через пробіл.
    **Вихід:** числа через пробіл після циклічного зсуву.
    **Приклад:** `input: "1 2 3 4 5" → output: "5 1 2 3 4"`

    Спробуй сам:

    ```task-runner {data-task-id="cyclic-shift"}
    # Виконай циклічний зсув вправо на 1 позицію
    ```

    ??? hint "Підказка"

        Скористайся зрізами: останній елемент — це `nums[-1:]`, а всі попередні — `nums[:-1]`. Об'єднай їх оператором `+`.

    ??? success "Розв'язок"

        ```python-runner
        nums = input().split()
        if len(nums) <= 1:
            print(" ".join(nums))
        else:
            shifted = [nums[-1]] + nums[:-1]
            print(" ".join(shifted))
        ```

!!! task "Задача 3. Розділення за парністю (Medium)"

    Дано послідовність чисел. Перестав елементи так, щоб спочатку йшли всі **парні** числа, а потім усі **непарні**. Відносний порядок чисел всередині парних та непарних груп має зберегтися.

    **Вхід:** рядок із цілими числами через пробіл.
    **Вихід:** переставлені числа через пробіл.
    **Приклад:** `input: "1 2 3 4 5 6" → output: "2 4 6 1 3 5"`

    Спробуй сам:

    ```task-runner {data-task-id="separate-parity"}
    # Розмісти спочатку парні, потім непарні
    ```

    ??? hint "Підказка"

        Зроби два спискових включення: одне відфільтрує `x % 2 == 0`, інше — `x % 2 != 0`. Потім склей їх: `evens + odds`.

    ??? success "Розв'язок"

        ```python-runner
        nums = [int(x) for x in input().split()]
        evens = [x for x in nums if x % 2 == 0]
        odds = [x for x in nums if x % 2 != 0]
        result = evens + odds
        print(" ".join(map(str, result)))
        ```

!!! task "Задача 4. Сума головної діагоналі матриці (Medium)"

    Дано квадратну матрицю розміром $N \times N$. Обчисли суму чисел, розташованих на її головній діагоналі (тобто елементів з однаковими індексами рядка і стовпця: $(0,0), (1,1), \dots, (N-1, N-1)$).

    **Вхід:** перший рядок містить число $N$ ($1 \le N \le 100$). Наступні $N$ рядків містять по $N$ цілих чисел.
    **Вихід:** одне число — сума елементів головної діагоналі.
    **Приклад:**
    ```
    input:
    3
    1 2 3
    4 5 6
    7 8 9
    output: 15
    ```

    Спробуй сам:

    ```task-runner {data-task-id="diag-sum"}
    # Обчисли суму головної діагоналі
    ```

    ??? hint "Підказка"

        Зчитуй кожен рядок $i$ ($0 \le i < N$) і додавай до загальної суми елемент на позиції $i$ цього рядка: `row[i]`.

    ??? success "Розв'язок"

        ```python-runner
        n = int(input())
        diag_sum = 0
        for i in range(n):
            row = [int(x) for x in input().split()]
            diag_sum += row[i]
        print(diag_sum)
        ```
