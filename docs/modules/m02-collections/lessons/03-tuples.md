# Кортежі

Кортеж (`tuple`) — це впорядкована колекція елементів, яка, на відміну від списку, є **незмінюваною** (*immutable*). Якщо список можна уявити як зошит, де можна виривати й додавати сторінки, то кортеж — це надрукована книга: її зміст зафіксовано назавжди.

Кортежі записуються у круглих дужках `(...)` або взагалі без дужок — просто через кому:

```python-runner
# Створення кортежу
point = (3, 7)
color = ("red", 255, 0, 0)
coords = 10, 20   # дужки необов'язкові!

print("Точка:", point)
print("X =", point[0], "Y =", point[1])
print("Довжина:", len(color))
```

## Створення та особливість одноелементного кортежу

Порожній кортеж створюється круглими дужками `()` або `tuple()`.

Але якщо ви хочете створити кортеж з **одного елемента**, виникає підступний нюанс синтаксису:

```python-runner
not_a_tuple = (42)    # ❌ Це просто число int у звичайних математичних дужках!
real_tuple = (42,)    # ✅ Кома обов'язкова!

print(type(not_a_tuple))  # <class 'int'>
print(type(real_tuple))   # <class 'tuple'>
```

!!! danger "Завжди ставте кому для одного елемента!"

    Вираз `(x)` обчислюється як вираз у дужках і повертає значення `x`. Щоб Python розпізнав це як кортеж, обов'язково поставте кому: `(x,)`.

## Навіщо потрібні кортежі, якщо є списки?

Часто постає питання: якщо список вміє все те саме, що й кортеж, та ще й дозволяє змінювати елементи, навіщо взагалі `tuple`?

Є три ключові причини:

1. **Захист від випадкових змін**: дані, передані як кортеж, гарантовано не будуть випадково модифіковані функцією чи циклом.
2. **Продуктивність і пам'ять**: кортежі займають менше оперативної пам'яті та створюються помітно швидше за списки.
3. **Хешованість (ключі у словниках і множинах)**: оскільки кортеж незмінюваний, його можна використовувати як ключ у словнику або елемент у множині `set`. Список так використовувати не можна!

```python-runner
# Кортеж як координата в лабіринті чи на шахівниці
visited = set()
visited.add((0, 0))
visited.add((1, 2))

# Словник з ключами-координатами:
board = {
    (0, 0): "Тура",
    (0, 1): "Кінь",
    (7, 4): "Король"
}
print("Хто на (0, 1):", board[(0, 1)])
# [0, 1] як ключ викличе TypeError: unhashable type: 'list'
```

## Розпакування кортежів (Tuple Unpacking)

Python дозволяє присвоювати елементи кортежу кільком змінним за один крок:

```python-runner
user = ("Олена", 16, "Київ")
name, age, city = user

print(f"{name}, {age} років, місто {city}")
```

Саме на механізмі кортежів побудовано знаменитий пітонівський обмін значеннями:

```python-runner
a = 10
b = 20
a, b = b, a   # справа створюється кортеж (b, a), зліва — розпаковується
print(f"a = {a}, b = {b}")
```

### Розширене розпакування з оператором `*`

Якщо кількість елементів невідома заздалегідь, залишок можна «зловити» зірочкою:

```python-runner
scores = [100, 85, 90, 78, 95]

first, *middle, last = scores
print("Переможець:", first)
print("Середні результати:", middle)
print("Останній:", last)
```

## Незамінні функції: `enumerate()` та `zip()`

Обидві ці функції повертають пари (кортежі), значно полегшуючи код.

### `enumerate()`: індекс та значення

Забудьте про `range(len(arr))`! `enumerate()` повертає кортеж `(індекс, елемент)`:

```python-runner
fruits = ["яблуко", "груша", "слива"]

for idx, fruit in enumerate(fruits, start=1):
    print(f"{idx}. {fruit}")
```

### `zip()`: об'єднання кількох послідовностей

`zip()` бере по черзі елементи з кількох списків і пакує їх у кортежі, поки не закінчиться найкоротший список:

```python-runner
names = ["Анна", "Богдан", "Ольга"]
points = [100, 92, 98]

for name, score in zip(names, points):
    print(f"Учень {name} набрав {score} балів")
```

## Сортування кортежів (Лексикографічний порядок)

У Python кортежі порівнюються поелементно зліва направо:
- спочатку порівнюються перші елементи: `(1, 100) < (2, 0)`, тому що $1 < 2$;
- якщо перші елементи однакові, порівнюються другі: `(2, 5) < (2, 8)`.

В олімпіадах це найпростіший спосіб сортувати об'єкти за кількома критеріями:

```python-runner
# Сортуємо список результатів олімпіади:
# 1. За спаданням балів (-score)
# 2. При однакових балах — за алфавітом імені
participants = [
    ("Богдан", 90),
    ("Анна", 95),
    ("Ольга", 90),
    ("Денис", 85)
]

# Сортуємо за кортежем (-бал, ім'я)
sorted_ranking = sorted(participants, key=lambda p: (-p[1], p[0]))
for name, score in sorted_ranking:
    print(f"{name}: {score}")
```

## Де? Як? Коли?

### 🌍 Де це використовується в реальному світі?

- **Робота з базами даних**: бібліотеки на кшталт `sqlite3` чи `psycopg2` повертають кожен рядок таблиці як кортеж значень.
- **Геодані та картографія**: географічні координати (широта, довгота) — це класичний незмінюваний кортеж `(lat, lon)`.
- **Кольорові моделі**: RGB-кольори `(255, 128, 0)` або RGBA.
- **Олімпіади**: ребра зваженого графа `(вага, вершина1, вершина2)` для алгоритмів Дейкстри та Крускала.

### ⚙️ Як це працює в Python?

- Оскільки довжина кортежу фіксована на етапі створення, Python не резервує додаткову пам'ять під можливі нові елементи (як у списку). Тому `sys.getsizeof(tuple)` завжди менший за `sys.getsizeof(list)`.
- Для маленьких кортежів (до 20 елементів) у CPython працює внутрішній пул пам'яті (*freelist*): при видаленні кортежу пам'ять не повертається ОС, а повторно використовується при створенні наступного, що робить операцію миттєвою.

### 🎯 Коли обирати / застосовувати?

- **Колекція змінюватиметься динамічно** $\rightarrow$ `list`.
- **Дані представляють одну логічну сутність фіксованого розміру** (наприклад, точка $(x, y)$, дата `(рік, місяць, день)`) $\rightarrow$ `tuple`.
- **Потрібно використати складну структуру як ключ у `dict` або зберегти в `set`** $\rightarrow$ тільки `tuple`!
- **Потрібно повернути з функції кілька значень** $\rightarrow$ `return a, b` (Python автоматично повертає кортеж).

## Типові помилки

!!! danger "Спроба змінити значення елемента кортежу"

```python-runner
point = (10, 20)
# point[0] = 99  # ❌ TypeError: 'tuple' object does not support item assignment

# ✅ Щоб "змінити", створіть новий кортеж:
point = (99, point[1])
print(point)
```

!!! danger "Кортеж, що містить список"

    Якщо кортеж містить змінюваний об'єкт (наприклад, `t = ([1, 2], 3)`), сам список змінювати можна (`t[0].append(4)`), але такий кортеж перестає бути хешованим і його не можна використовувати як ключ словника.

!!! task "Задача 3. Сортування точок за координатами (Medium)"

    Дано $N$ точок на площині. Кожна точка задається парою цілих чисел $(x, y)$. Відсортуй точки за координатою $x$ за зростанням. Якщо координати $x$ збігаються, відсортуй за координатою $y$ за зростанням.

    **Вхід:** перший рядок містить $N$ ($1 \le N \le 1000$). Наступні $N$ рядків містять по два числа $x$ та $y$.
    **Вихід:** $N$ рядків, у кожному по два числа — відсортовані координати точок.
    **Приклад:**
    ```
    input:
    3
    2 5
    1 9
    2 3
    output:
    1 9
    2 3
    2 5
    ```

    Спробуй сам:

    ```task-runner {data-task-id="sort-tuples"}
    # Відсортуй точки за (x, y)
    ```

    ??? hint "Підказка"

        Збережи кожну точку як кортеж `(x, y)`. Оскільки в Python кортежі за замовчуванням порівнюються спочатку за першим елементом, а потім за другим, стандартна функція `points.sort()` розв'яже задачу в один рядок!

    ??? success "Розв'язок"

        ```python-runner
        n = int(input())
        points = []
        for _ in range(n):
            x, y = map(int, input().split())
            points.append((x, y))
        points.sort()
        for x, y in points:
            print(f"{x} {y}")
        ```

!!! task "Задача 4. Розпакування зі зірочкою (Medium)"

    Дано один рядок із даними про студента: першим іде ім'я, останнім — статус складання екзамену (`Passed` або `Failed`), а між ними — довільна кількість оцінок (принаймні одна).
    Обчисли середній бал студента (округлений до 1 знака після коми) і виведи результат у форматі: `Ім'я: Середній_бал (Статус)`.

    **Вхід:** рядок із даними.
    **Вихід:** відформатований рядок.
    **Приклад:** `input: "Ivan 10 12 11 9 Passed" → output: "Ivan: 10.5 (Passed)"`

    Спробуй сам:

    ```task-runner {data-task-id="star-unpacking"}
    # Використай розширене розпакування з зірочкою
    ```

    ??? hint "Підказка"

        Розбий рядок на частини: `tokens = input().split()`. Потім розпакуй: `name, *grades, status = tokens`. Перетвори `grades` на числа через `[float(g) for g in grades]` і обчисли середнє арифметичне.

    ??? success "Розв'язок"

        ```python-runner
        tokens = input().split()
        name, *grades, status = tokens
        num_grades = [float(g) for g in grades]
        avg = sum(num_grades) / len(num_grades)
        print(f"{name}: {avg:.1f} ({status})")
        ```
