# Словники

Словник (`dict`) — це фундаментальна структура даних у Python, яка зберігає пари **«ключ — значення»**. Якщо в звичайному списку елементи нумеруються цілими числами $0, 1, 2, \dots$, то в словнику ключем може бути будь-який незмінюваний об'єкт: рядок, число чи навіть кортеж.

Під капотом словник реалізовано як високоефективну **хеш-таблицю**. Це означає, що пошук значення за ключем, додавання нового елемента та видалення виконуються майже миттєво — за **$O(1)$** часу, незалежно від того, чи в словнику 10 елементів, чи 10 мільйонів!

```python-runner
# Створення словника
capitals = {
    "Україна": "Київ",
    "Польща": "Варшава",
    "Франція": "Париж"
}

# Доступ та додавання нових значень за O(1)
print("Столиця України:", capitals["Україна"])
capitals["Німеччина"] = "Берлін"   # додали новий запис
print("Словник:", capitals)
```

## Створення словників та доступ до даних

Словники позначаються фігурними дужками `{...}`. Ключ і значення відокремлюються двокрапкою:

```python-runner
empty_dict = {}                   # порожній словник
user = {"name": "Іван", "age": 16, "city": "Львів"}

# Безпечний доступ: get() vs пряме звернення []
print("Ім'я:", user["name"])

# Якщо ключа немає:
# print(user["rating"])           # ❌ KeyError!
print("Рейтинг:", user.get("rating", 0))  # ✅ поверне 0 (значення за замовчуванням)
```

!!! tip "Метод .get() рятує від аварійних зупинок"

    Виклик `d.get(key, default)` повертає значення за ключем `key`. Якщо ж ключ не знайдено, замість аварійної зупинки помилкою `KeyError` він повертає значення `default` (або `None`, якщо `default` не вказано).

## Зміна, додавання та видалення ключів

| Дія | Синтаксис | Складність |
|---|---|---|
| Додати або змінити | `d[key] = value` | $O(1)$ |
| Безпечно отримати | `d.get(key, default)` | $O(1)$ |
| Перевірити наявність ключа | `key in d` | $O(1)$ |
| Видалити за ключем | `del d[key]` | $O(1)$ |
| Витягнути та видалити | `d.pop(key, default)` | $O(1)$ |
| Очистити словник | `d.clear()` | $O(1)$ |

```python-runner
scores = {"Богдан": 85, "Ольга": 92}

scores["Богдан"] = 95       # оновлення існуючого ключа
scores["Андрій"] = 78       # додавання нового ключа
del scores["Ольга"]         # видалення
removed = scores.pop("Андрій")

print("Залишилось:", scores)
print("Видалили:", removed)
```

## Ітерація по словнику

Словник надає три зручні методи для перегляду вмісту:

1. `d.keys()` — колекція ключів (за замовчуванням при `for k in d`).
2. `d.values()` — колекція значень.
3. `d.items()` — пари `(ключ, значення)` у вигляді кортежів.

```python-runner
inventory = {"яблуко": 10, "груша": 5, "апельсин": 8}

print("--- Тільки ключі ---")
for item in inventory:
    print(item, end=" ")
print()

print("--- Ключ і значення разом ---")
for item, count in inventory.items():
    print(f"{item} -> {count} шт.")
```

## Вимоги до ключів: властивість Hashable

Ключем словника може бути **лише незмінюваний (хешований) об'єкт**:
- ✅ `int`, `float`, `str`, `bool`, `tuple` (якщо всі елементи кортежу теж хешовані).
- ❌ `list`, `dict`, `set` — не можуть бути ключами, оскільки є змінюваними.

```python-runner
# ✅ Кортеж як ключ — чудово працює!
point_values = {(0, 0): "Старт", (5, 5): "Фініш"}
print(point_values[(0, 0)])

# ❌ Список як ключ:
# bad = {[1, 2]: "помилка"}  # TypeError: unhashable type: 'list'
```

## Частотний словник: головний олімпіадний патерн

Найчастіше застосування словника в олімпіадах — **підрахунок кількості зустрічей кожного елемента** за один прохід ($O(n)$):

```python-runner
words = ["яблуко", "груша", "яблуко", "слива", "яблуко", "груша"]

freq = {}
for w in words:
    freq[w] = freq.get(w, 0) + 1

for word, count in freq.items():
    print(f"{word}: {count}")
```

### Модуль `collections`: `Counter` та `defaultdict`

У стандартній бібліотеці Python є готові помічники:

```python-runner
from collections import Counter, defaultdict

# Counter робить частотний словник в один рядок:
c = Counter(["a", "b", "a", "c", "b", "a"])
print("Counter:", c)
print("Топ-1 найчастіший:", c.most_common(1))

# defaultdict автоматично створює значення за замовчуванням
groups = defaultdict(list)
words = ["кіт", "пес", "кит", "слон", "рак"]
for w in words:
    groups[len(w)].append(w)  # якщо ключа len(w) немає, створюється пустий []
print("Групи за довжиною:", dict(groups))
```

## Де? Як? Коли?

### 🌍 Де це використовується в реальному світі?

- **Формат JSON та API веб-сервісів**: відповіді бекенду, налаштування та конфігураційні файли (JSON і є словником).
- **Кешування (Memoization)**: збереження результатів важких функцій за параметрами-ключами, щоб не рахувати двічі.
- **Бази даних ключ-значення**: Redis, Memcached, DynamoDB.
- **Олімпіади**: підрахунок частот, анаграми, швидкий пошук пар із заданою сумою (Two Sum), мемоізація в динамічному програмуванні.

### ⚙️ Як це працює в Python?

- Словник реалізований як компактна хеш-таблиця. При додаванні пари `(k, v)` обчислюється хеш `hash(k)`. За цим хешем визначається комірка пам'яті. Завдяки розв'язанню колізій доступ відбувається в середньому за $O(1)$.
- Починаючи з Python 3.7, словники **гарантовано зберігають порядок додавання ключів**!

### 🎯 Коли обирати / застосовувати?

- **Потрібен миттєвий пошук за ім'ям, ідентифікатором чи координатами** $\rightarrow$ `dict`.
- **Потрібно порахувати, скільки разів трапляється кожен елемент** $\rightarrow$ `dict` або `Counter`.
- **Потрібно згрупувати елементи за категорією чи властивістю** $\rightarrow$ `defaultdict(list)`.
- **Потрібні лише унікальні елементи без значень** $\rightarrow$ `set` (множина).

## Типові помилки

!!! danger "Звернення до неіснуючого ключа через []"

```python-runner
d = {"a": 1, "b": 2}
# x = d["c"]  # ❌ KeyError: 'c'

# ✅ Завжди використовуйте .get() або перевірку 'in':
x = d.get("c", 0)
print("Безпечний x:", x)
```

!!! danger "Зміна розміру словника під час ітерації"

    Ніколи не додавайте і не видаляйте ключі прямо в циклі `for k in d: del d[k]`. Це викличе `RuntimeError: dictionary changed size during iteration`. Якщо потрібно видалити ключі, ітеруйтеся по копії списку ключів: `for k in list(d.keys()): ...`.

    **Вихід:** символ та кількість входжень через пробіл.
    **Приклад:** `input: "abracadabra" → output: "a 5"`

    Спробуй сам:

    ```task-runner {data-task-id="most-frequent-char"}
    # Знайди найчастіший символ
    ```

    ??? hint "Підказка"

        Порахуй кількість входжень кожного символу в словник. Потім відсортуй пари `(символ, частота)` за двома критеріями: за спаданням частоти (`-частота`) та за зростанням символу за алфавітом.

    ??? success "Розв'язок"

        ```python-runner
        s = input().strip()
        counts = {}
        for ch in s:
            counts[ch] = counts.get(ch, 0) + 1

        # Сортуємо: пріоритет 1 — частота спадає (-freq), пріоритет 2 — символ за зростанням (ch)
        best_char = sorted(counts.keys(), key=lambda ch: (-counts[ch], ch))[0]
        print(f"{best_char} {counts[best_char]}")
        ```

!!! task "Задача 4. Групування слів за довжиною (Medium)"

    Дано рядок слів через пробіл. Згрупуй слова за їхньою довжиною та виведи групи в порядку зростання довжини слів. Всередині кожної групи слова повинні йти в тому порядку, у якому вони зустрілися у вхідному рядку. Формат виведення для кожної групи: `довжина: слово1 слово2 ...`.

    **Вхід:** рядок зі словами через пробіл.
    **Вихід:** рядки із групами за довжиною.
    **Приклад:**
    ```
    input: cat dog bird fish apple
    output:
    3: cat dog
    4: bird fish
    5: apple
    ```

    Спробуй сам:

    ```task-runner {data-task-id="group-by-len"}
    # Згрупуй слова за довжиною
    ```

    ??? hint "Підказка"

        Створи словник списків `groups = {}`, де ключем буде `len(w)`. Додавай слова у відповідні списки: `groups.setdefault(len(w), []).append(w)`. Потім відсортуй ключі `sorted(groups.keys())`.

    ??? success "Розв'язок"

        ```python-runner
        words = input().split()
        groups = {}
        for w in words:
            length = len(w)
            if length not in groups:
                groups[length] = []
            groups[length].append(w)

        for length in sorted(groups.keys()):
            print(f"{length}: {' '.join(groups[length])}")
        ```
