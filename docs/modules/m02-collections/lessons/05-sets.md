# Множини

Множина (`set`) — це невпорядкована колекція **виключно унікальних** елементів. У множині не може бути дублікатів: якщо ви спробуєте додати елемент, який там уже присутній, множина просто проігнорує його.

Як і словник, множина побудована на базі **хеш-таблиці**. Завдяки цьому головна операція — перевірка того, чи належить елемент множині (`x in my_set`), виконується з блискавичною швидкістю **$O(1)$**.

```python-runner
# Створення множини та усунення дублікатів
raw_data = [1, 2, 2, 3, 4, 4, 4, 5]
unique_items = set(raw_data)
print("Унікальні числа:", unique_items)

# Миттєва перевірка за O(1)
print("Чи є число 3 у множині?", 3 in unique_items)
print("Чи є число 100 у множині?", 100 in unique_items)
```

## Створення множин та особливість порожньої множини

Множини записуються у фігурних дужках `{...}` через кому:

```python-runner
primes = {2, 3, 5, 7, 11}
letters = set("abracadabra")  # розбиває рядок на унікальні літери
print("Унікальні літери:", letters)

# ⚠️ УВАГА: порожня множина
empty_dict = {}          # це СЛОВНИК, а не множина!
empty_set = set()        # ✅ єдиний спосіб створити порожню множину

print(type(empty_dict))  # <class 'dict'>
print(type(empty_set))   # <class 'set'>
```

!!! danger "{} створює словник, а не множину!"

    Оскільки словники в Python з'явилися раніше за множини, запис `{}` зарезервований під порожній словник. Щоб створити порожню множину, завжди викликайте `set()`.

## Додавання та видалення елементів

| Метод | Що робить | Якщо елемента немає | Складність |
|---|---|---|---|
| `s.add(x)` | Додає елемент `x` | Нічого не ламає (ігнорує дублікат) | $O(1)$ |
| `s.remove(x)` | Видаляє елемент `x` | Викидає `KeyError` | $O(1)$ |
| `s.discard(x)` | Безпечно видаляє елемент `x` | Тихо ігнорує (без помилки) | $O(1)$ |
| `s.pop()` | Видаляє і повертає випадковий елемент | Викидає `KeyError` на порожній множині | $O(1)$ |
| `s.clear()` | Очищає множину | — | $O(1)$ |

```python-runner
tags = {"python", "olymp"}
tags.add("algorithms")
tags.add("python")       # дублікат не додасться!
print("Після add:", tags)

tags.discard("pascal")   # безпечне видалення — помилки немає
tags.remove("olymp")     # видалення існуючого
print("Фінал:", tags)
```

## Теоретико-множинні операції

Python підтримує всі класичні операції з теорії множин як через оператори, так і через методи.

Нехай задано дві множини: $A = \{1, 2, 3\}$ та $B = \{3, 4, 5\}$.

```
 Об'єднання (A | B)       Перетин (A & B)         Різниця (A - B)       Сим. різниця (A ^ B)
   {1, 2, 3, 4, 5}              {3}                   {1, 2}                {1, 2, 4, 5}
```

```python-runner
a = {1, 2, 3}
b = {3, 4, 5}

print("Об'єднання (A | B):", a | b)          # всі елементи з A та B
print("Перетин (A & B):", a & b)             # спільні елементи
print("Різниця (A - B):", a - b)             # є в A, але немає в B
print("Симетрична різниця (A ^ B):", a ^ b)  # є рівно в одній з множин
```

### Перевірка підмножини

- `A <= B` або `A.issubset(B)` — чи є $A$ підмножиною $B$ (всі елементи $A$ містяться в $B$).
- `A >= B` або `A.issuperset(B)` — чи є $A$ надмножиною $B$.

```python-runner
small = {1, 2}
big = {1, 2, 3, 4}
print("small підмножина big?", small <= big)   # True
```

## Чому перевірка `in` у множині швидша за список?

У списку `x in my_list` перевіряє кожен елемент по черзі від початку до кінця (лінійний пошук, $O(n)$). Якщо в списку $10^5$ елементів, на $10^5$ запитів знадобиться $10^{10}$ операцій — це займе кілька хвилин і призведе до TLE в олімпіаді!

У множині `x in my_set` обчислюється хеш числа і виконується один прямий стрибок у пам'ять ($O(1)$). $10^5$ перевірок займуть менше $0.05$ секунди!

```python-runner
# Перевірка швидкості:
large_set = set(range(100000))
large_list = list(range(100000))

# В обох колекціях шукаємо елемент:
print("В множині 99999 є?", 99999 in large_set)   # миттєво O(1)
print("В списку 99999 є?", 99999 in large_list)   # мусить пройти 100 000 кроків O(n)
```

## Незмінювані множини: `frozenset`

Звичайна множина `set` є змінюваною, тому її **не можна** покласти в іншу множину або зробити ключем словника.

Для таких випадків існує `frozenset` — заморожена незмінювана версія множини:

```python-runner
# Множина множин:
group1 = frozenset([1, 2])
group2 = frozenset([3, 4])
set_of_sets = {group1, group2}
print("Множина множин:", set_of_sets)
```

## Де? Як? Коли?

### 🌍 Де це використовується в реальному світі?

- **Усунення дублікатів**: очищення бази підписників від повторних email-адрес.
- **Аналітика та рекомендації**: пошук спільних друзів у соцмережах (перетин множин друзів `friends_A & friends_B`).
- **Контроль доступу**: перевірка наявності дозволів у ролі користувача (`user_permissions >= required_permissions`).
- **Олімпіади**: алгоритми на графах (множина відвіданих вершин `visited`), перевірка наявності числа серед раніше побачених за $O(1)$.

### ⚙️ Як це працює в Python?

- `set` — це словник, у якому зберігаються лише ключі без значень.
- Оскільки елементи зберігаються за хеш-кодом у комірках внутрішньої таблиці, **порядок елементів у множині не гарантується** і може змінюватися між запусками інтерпретатора.

### 🎯 Коли обирати / застосовувати?

- **Потрібно гарантувати унікальність елементів** $\rightarrow$ `set`.
- **Потрібно швидко перевіряти наявність елемента (`x in ...`)** $\rightarrow$ `set`.
- **Потрібно знайти спільні або відмінні елементи двох колекцій** $\rightarrow$ оператори `&`, `-`, `^`.
- **Потрібно зберегти порядок елементів або індексацію** $\rightarrow$ `list`.

## Типові помилки

!!! danger "Спроба звернутися за індексом"

    Множина не має порядку та індексів!

```python-runner
s = {10, 20, 30}
# print(s[0])   # ❌ TypeError: 'set' object is not subscriptable

# ✅ Якщо потрібен елемент за індексом, перетворіть на список або відсортуйте:
sorted_list = sorted(s)
print("Перший елемент відсортованого:", sorted_list[0])
```

!!! danger "Спроба додати список або словник у множину"

    Елементами множини можуть бути лише незмінювані об'єкти (`int`, `str`, `tuple`, `frozenset`).

```python-runner
s = set()
# s.add([1, 2])   # ❌ TypeError: unhashable type: 'list'
s.add((1, 2))     # ✅ Кортеж хешований і чудово підходить
print(s)
```

!!! task "Задача 3. Панграма (Medium)"

    **Панграма** — це речення, яке містить усі 26 літер англійського алфавіту хоча б один раз.

    **Приклад:** `input: "The quick brown fox jumps over the lazy dog" → output: "YES"`

    Спробуй сам:

    ```task-runner {data-task-id="is-pangram"}
    # Перевір, чи рядок є панграмою
    ```

    ??? hint "Підказка"

        Витягни всі літери рядка в нижньому регістрі у множину: `{ch for ch in s.lower() if 'a' <= ch <= 'z'}`. Якщо розмір цієї множини дорівнює 26, це панграма.

    ??? success "Розв'язок"

