## Розділ 1. Рядки та списки

!!! task "Задача 1. Статистика рядка (Easy)"

    Дано текстовий рядок. Порахуй і виведи через пробіл три числа:
    1. Кількість слів у рядку (слова відокремлені одним або кількома пробілами).
    2. Кількість літер (латинських або кириличних, `isalpha() == True`).
    3. Кількість цифр (`isdigit() == True`).

    **Вхід:** один рядок тексту.
    **Вихід:** три числа через пробіл: `слова літери цифри`.
    **Приклад:** `input: "Hello, World! 2026" → output: "3 10 4"`

    Спробуй сам:

    ```task-runner {data-task-id="text-stats"}
    # Збери статистику рядка
    ```

    ??? hint "Підказка"

        Кількість слів — це `len(s.split())`. Кількість літер і цифр можна порахувати за один прохід по всіх символах рядка, перевіряючи `ch.isalpha()` та `ch.isdigit()`.

    ??? success "Розв'язок"

        ```python-runner
        s = input()
        words_count = len(s.split())
        letters_count = sum(1 for ch in s if ch.isalpha())
        digits_count = sum(1 for ch in s if ch.isdigit())
        print(f"{words_count} {letters_count} {digits_count}")
        ```

!!! task "Задача 2. Унікальні зі збереженням порядку (Easy)"

    Дано послідовність цілих чисел. Видали всі дублікати, зберігши **первинний порядок** першої появи кожного числа (тобто кожне число має зустрітися у вихідному списку рівно один раз на тій позиції, де воно трапилося вперше).

    **Вхід:** один рядок чисел через пробіл.
    **Вихід:** унікальні числа через пробіл у порядку першої появи.
    **Приклад:** `input: "1 3 2 1 4 3 5" → output: "1 3 2 4 5"`

    Спробуй сам:

    ```task-runner {data-task-id="unique-preserve-order"}
    # Видали дублікати зі збереженням порядку
    ```

    ??? hint "Підказка"

        Звичайна функція `set(nums)` видалить повтори, але зламає порядок чисел. Заведіть порожню множину `seen = set()` для швидкої перевірки за $O(1)$ і результуючий список `res = []`. Додавайте число в `res` лише тоді, коли його ще немає в `seen`.

    ??? success "Розв'язок"

        ```python-runner
        nums = input().split()
        seen = set()
        result = []
        for x in nums:
            if x not in seen:
                seen.add(x)
                result.append(x)
        print(" ".join(result))
        ```

## Розділ 2. Словники та підрахунки

!!! task "Задача 3. Найчастіше слово (Medium)"

    Дано текст, що складається зі слів, розділених пробілами. Знайди слово, яке зустрічається найчастіше. Регістр літер не має значення (перед підрахунком приведи всі слова до нижнього регістру).
    Якщо кілька слів зустрічаються однакову максимальну кількість разів, виведи те, яке є найменшим у лексикографічному (алфавітному) порядку.

    **Вхід:** рядок зі словами.
    **Вихід:** слово в нижньому регістрі та кількість його входжень через пробіл.
    **Приклад:** `input: "apple banana apple orange banana apple" → output: "apple 3"`

    Спробуй сам:

    ```task-runner {data-task-id="most-frequent-word"}
    # Знайди найчастіше слово
    ```

    ??? hint "Підказка"

        Побудуй частотний словник через `Counter(words)` або звичайний цикл. Потім відсортуй пари слів за ключем: `key=lambda w: (-counts[w], w)`.

    ??? success "Розв'язок"

        ```python-runner
        words = input().strip().lower().split()
        counts = {}
        for w in words:
            counts[w] = counts.get(w, 0) + 1

        best_word = sorted(counts.keys(), key=lambda w: (-counts[w], w))[0]
        print(f"{best_word} {counts[best_word]}")
        ```

!!! task "Задача 4. Два числа із заданою сумою (Two Sum) (Medium)"

    Дано число $N$ ($2 \le N \le 10^5$), цільову суму $S$ та масив із $N$ цілих чисел.
    Визнач, чи існують у масиві **два різних елементи** на різних позиціях, сума яких дорівнює $S$.

    **Вхід:** перший рядок містить $N$ та $S$ через пробіл. Другий рядок містить $N$ цілих чисел.
    **Вихід:** `YES`, якщо така пара чисел існує, і `NO` в іншому випадку.
    **Обмеження:** $O(N)$ часу. Вкладені цикли $O(N^2)$ не пройдуть за часом!
    **Приклад:**
    ```
    input:
    5 10
    1 4 6 8 3
    output: YES
    ```
    *(Пояснення: 4 + 6 = 10)*

    Спробуй сам:

    ```task-runner {data-task-id="two-sum"}
    # Знайди два числа з сумою S за O(N)
    ```

    ??? hint "Підказка"

        Ітеруйся по числах. Для кожного числа $x$ нам потрібен партнер $target = S - x$. Перевір, чи є $target$ у множині раніше бачених чисел `seen`. Якщо є — відповідь `YES`! Якщо ні — додай $x$ у `seen`.

    ??? success "Розв'язок"

        ```python-runner
        n, s = map(int, input().split())
        nums = [int(x) for x in input().split()]

        seen = set()
        found = False
        for x in nums:
            complement = s - x
            if complement in seen:
                found = True
                break
            seen.add(x)

        if found:
            print("YES")
        else:
            print("NO")
        ```

## Розділ 3. Олімпіадні алгоритми

!!! task "Задача 5. Злиття відсортованих списків за O(N + M) (Medium)"

    Дано два списки чисел, кожен з яких уже відсортований за неспападанням. Об'єднай їх в один загальний відсортований список.
    **Умова:** заборонено об'єднувати списки і викликати функцію `sort()`! Використай метод двох покажчиків, щоб злити списки за лінійний час $O(N + M)$.

    **Вхід:** перший рядок містить числа першого списку через пробіл. Другий рядок — числа другого списку.
    **Вихід:** відсортований список чисел через пробіл.
    **Приклад:**
    ```
    input:
    1 3 5 7
    2 4 6 8
    output: 1 2 3 4 5 6 7 8
    ```

    Спробуй сам:

    ```task-runner {data-task-id="merge-sorted"}
    # Злий два списки за O(N+M) без .sort()
    ```

    ??? hint "Підказка"

        Заведи два індекси `i = 0` та `j = 0`. Поки обидва індекси не вийшли за межі, порівнюй `a[i]` та `b[j]`: менший елемент додавай до результату і зсувай відповідний індекс. У кінці додай залишок списку, який ще не закінчився.

    ??? success "Розв'язок"

        ```python-runner
        a = [int(x) for x in input().split()]
        b = [int(x) for x in input().split()]

        i = 0
        j = 0
        merged = []

        while i < len(a) and j < len(b):
            if a[i] <= b[j]:
                merged.append(a[i])
                i += 1
            else:
                merged.append(b[j])
                j += 1

        # Додаємо залишки
        if i < len(a):
            merged.extend(a[i:])
        if j < len(b):
            merged.extend(b[j:])

        print(" ".join(map(str, merged)))
        ```

!!! task "Задача 6. Анаграматичні групи (Medium)"

    Дано рядок слів через пробіл. Слова, які є анаграмами одне одного, належать до однієї групи.
    Знайди загальну кількість таких груп анаграм, а також розмір найбільшої групи.

    **Вхід:** рядок зі словами в нижньому регістрі через пробіл.
    **Вихід:** два числа через пробіл: `кількість_груп розмір_найбільшої`.
    **Приклад:** `input: "eat tea tan ate nat bat" → output: "3 3"`
    *(Групи: [eat, tea, ate] розміром 3; [tan, nat] розміром 2; [bat] розміром 1. Разом 3 групи, максимум 3).*

    Спробуй сам:

    ```task-runner {data-task-id="anagram-groups"}
    # Порахуй кількість груп анаграм та максимальний розмір
    ```

    ??? hint "Підказка"

        У двох слів-анаграм відсортовані літери збігаються: `"".join(sorted("tea")) == "aet"`. Використай цей відсортований рядок як ключ у словнику списків.

    ??? success "Розв'язок"

        ```python-runner
        words = input().split()
        groups = {}
        for w in words:
            key = "".join(sorted(w))
            if key not in groups:
                groups[key] = []
            groups[key].append(w)

        num_groups = len(groups)
        max_size = max(len(lst) for lst in groups.values())
        print(f"{num_groups} {max_size}")
        ```

!!! task "Задача 7. Найдовша послідовність послідовних чисел (Hard)"

    Дано невідсортований масив цілих чисел. Знайди довжину найдовшої послідовності чисел вигляду $k, k+1, k+2, \dots$, які присутні в масиві (порядок у вихідному масиві значення не має).
    
    Алгоритм повинен працювати за **$O(N)$** часу! Сортування масиву займає $O(N \log N)$ і для великих $N$ не підходить.

    **Вхід:** один рядок цілих чисел через пробіл.
    **Вихід:** одне ціле число — довжина найдовшої послідовної ланки.
    **Приклад:** `input: "100 4 200 1 3 2" → output: "4"`
    *(Пояснення: числа 1, 2, 3, 4 утворюють послідовність довжиною 4).*

    Спробуй сам:

    ```task-runner {data-task-id="longest-consecutive"}
    # Знайди найдовшу послідовність за O(N)
    ```

    ??? hint "Підказка"

        1. Помісти всі числа у множину `nums_set = set(nums)`.
        2. Число $x$ є початком нової послідовності тоді й тільки тоді, коли в множині **немає** $x - 1$.
        3. Якщо $x - 1 \notin nums\_set$, запускай цикл `while curr + 1 in nums_set:` і рахуй довжину ланцюжка. Оскільки кожне число відвідується не більше двох разів, сумарний час складе $O(N)$!

    ??? success "Розв'язок"

        ```python-runner
        nums = [int(x) for x in input().split()]
        if not nums:
            print(0)
        else:
            nums_set = set(nums)
            max_len = 0
            for x in nums_set:
                # Перевіряємо, чи x є початком ланцюжка
                if x - 1 not in nums_set:
                    curr = x
                    curr_len = 1
                    while curr + 1 in nums_set:
                        curr += 1
                        curr_len += 1
                    if curr_len > max_len:
                        max_len = curr_len
            print(max_len)
        ```
