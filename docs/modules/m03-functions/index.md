# Модуль 3. Функції

Функції — це **іменовані блоки коду**, які можна викликати багато разів.
Вони роблять код коротшим, зрозумілішим і придатним для повторного
використання.

## Уроки

1. **Визначення функцій** — `def`, `return`, документація
2. **Параметри та аргументи** — позиційні, іменовані, `*args`, `**kwargs`
3. **Області видимості** — LEGB, `global`, `nonlocal`
4. **Функції вищого порядку** — `map`, `filter`, `sorted`, `lambda`
5. **Задачі модуля 3**
