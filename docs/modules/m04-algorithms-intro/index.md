# Модуль 4. Вступ до алгоритмів

Тут починається справжня олімпіадна підготовка. Ми навчимося **вимірювати
ефективність** алгоритмів, порівнювати підходи і вибирати оптимальний.

## Уроки

1. **Асимптотика** — O-нотація, Ω, Θ
2. **Лінійний пошук** — `O(n)`, простий, але повільний
3. **Бінарний пошук** — `O(log n)`, вимагає відсортований масив
4. **Два покажчики** — техніка для масивів і рядків
5. **Префіксні суми** — миттєві запити на відрізках
