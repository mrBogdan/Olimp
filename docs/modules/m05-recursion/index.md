# Модуль 5. Рекурсія

Рекурсія — це коли функція викликає **сама себе**. Це потужний інструмент
для задач, які можна розбити на підзадачі того ж типу: дерева, графи,
фрактали, розбір виразів.

## Уроки

1. **Базовий випадок і рекурсивний крок** — фундамент
2. **Рекурсія vs ітерація** — коли що обрати
3. **Мемоізація** — прискорюємо рекурсію в рази
4. **Рекурсія на масивах** — бінарний пошук, двійковий пошук
5. **Класичні задачі** — Ханойські вежі, числа Фібоначчі, n-Queens
6. **Задачі модуля 5**
