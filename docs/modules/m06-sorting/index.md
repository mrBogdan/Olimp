# Модуль 6. Сортування

Сортування — одна з найбільш вивчених задач в інформатиці. Розуміння
алгоритмів сортування допомагає не лише впорядковувати дані, а й будувати
інші алгоритми (бінарний пошук, жадібні, divide & conquer).

## Уроки

1. **Бульбашкове сортування** — `O(n²)`, найпростіше
2. **Сортування вибором і вставкою** — `O(n²)`, але практичніше
3. **Швидке сортування (QuickSort)** — `O(n log n)` у середньому
4. **Сортування злиттям (MergeSort)** — `O(n log n)` гарантовано
5. **Вбудовані функції Python** — `sorted()`, `.sort()`, `key=`
