# Модуль 7. Структури даних

Правильна структура даних може перетворити `O(n²)` на `O(n log n)`. У цьому
модулі ми вивчимо класичні структури, які лежать в основі бібліотек і
олімпіадних рішень.

## Уроки

1. **Стек** — LIFO, дужки, DFS
2. **Черга та дек** — FIFO, BFS
3. **Зв'язний список** — основа для складних структур
4. **Бінарне дерево пошуку (BST)** — пошук за `O(log n)`
5. **Купа (heap)** — пріоритетна черга, `heapq`
6. **Хеш-таблиця зсередини** — як працює `dict`
7. **Задачі модуля 7**

- [x] використовувати `heapq` для пріоритетної черги
