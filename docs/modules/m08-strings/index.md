# Модуль 8. Рядки та підрядки

Робота з рядками — окрема олімпіадна дисципліна. Тут ми розберемо
класичні алгоритми пошуку підрядків і хешування.

## Уроки

1. **Базові операції з рядками** — `find`, `replace`, `split`
2. **Префікс-функція** — основа для KMP
3. **Алгоритм Кнута-Морріса-Пратта (KMP)** — `O(n+m)`
4. **Z-функція** — альтернативний спосіб
5. **Поліноміальне хешування** — швидке порівняння підрядків
6. **Бор (trie)** — структура для префіксних запитів
