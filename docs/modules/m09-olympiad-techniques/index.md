# Модуль 9. Олімпіадні техніки

Заключний модуль — це інструменти й патерни, які не прив'язані до однієї
теми, але постійно зустрічаються на олімпіадах.

## Уроки

1. **Бітові операції** — маски, XOR-трюки, підмножини
2. **Жадібні алгоритми** — коли працюють і коли ні
3. **Divide & Conquer** — не тільки сортування
4. **Двійковий пошук за відповіддю** — бінарний пошук не лише в масивах
5. **Типові патерни** — two pointers, sliding window, off-by-one
6. **Архів задач** — добірка з минулих олімпіад

- [x] доводити коректність жадібних алгоритмів
- [x] застосовувати бінарний пошук за відповіддю
- [x] впевнено розв'язувати задачі рівня обласної олімпіади
